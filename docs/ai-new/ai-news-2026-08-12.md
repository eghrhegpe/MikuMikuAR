## ① 智谱 ZCode 用户突破 100 万，上线 Goal / Subagents / Remote Control / 闲时任务

**事件内容**
8 月 11 日，智谱 AI 编程产品 ZCode 宣布全面升级，用户数突破 100 万，新增四项能力：
- **Goal**：面向复杂任务的自主目标拆解与交付
- **Subagents**：子 Agent 并行执行
- **Remote Control**：远程受控执行
- **闲时任务**：低峰期排队跑长任务

智谱自研 Z.ai Code Bench 称 GLM-5.2 + ZCode 的整体通过率较 GLM-5.2 + Claude Code 高 **2.39%**，优势集中在跨文件、跨环节协作并最终验收的复杂任务。同时通过缓存命中率优化将 GLM Coding Plan 有效额度提升约 30%。

**值得关注的原因**
国产 Coding Harness 首次明确跑出"基础模型 + Harness + 订阅"三位一体生态闭环，且以百万级用户体量切入。其强调的"跨文件协作 + 最终验收"恰好是当下 agent 从 demo 走向生产的核心瓶颈，对联邦的 action-defs / 桥接解耦架构有参照价值——Harness 层的编排能力正在成为差异化主战场，而非单纯模型跑分。

## ② Anthropic 开放 Agent Skills 公共仓库，Addy Osmani 发布 agent-skills 生产级工程框架

**事件内容**
8 月 11 日 GitHub Trending 两条相关动态：
- **Anthropic** 正式发布 `Agent Skills` 公共仓库，给出 Claude 专用的 Skills 实现，并指向 agentskills.io 标准，推动 agent 与工具交互方式标准化。
- 知名工程师 **Addy Osmani** 开源 `agent-skills` 项目，目标是把工程工作流、质量门禁（quality gates）、行业最佳实践直接编码进 agent 的运行逻辑，使自主 agent 不止生成代码，更遵循生产级工程标准。

**值得关注的原因**
Coding Agent 的竞争焦点正从"模型能力"外溢到"工程纪律内建"。质量门禁、可审计、标准化 Skills 分发——这与联邦近期推进的 ADR-238（action-defs 注册表解耦）和"harness > 模型"判断高度同频。Agent Skills 标准化也呼应 8 月初 Amazon/Cursor/Microsoft/OpenAI/Vercel 联合推出的 plugin.json 打包标准，生态碎片化正在被治理。

## ③ 清华 × 腾讯 Robotics X × 港科大 发布 GeniWorld：可交互机器人世界模型，真机成功率 40.8% → 69.0%

**事件内容**
研究团队提出 **GeniWorld**——基于具身视觉动作条件化的通用交互式世界模型。核心创新是用 URDF 渲染将数值动作序列转为"视觉化动作表示"，再驱动因果扩散 Transformer 预测未来视频帧，形成"想象空间"中的闭环交互。

配合 GeniWorld 合成数据后，π0 VLA 模型在**空间重排、新物体实例、光照变化**等 OOD 场景下的总体成功率从 **40.8% 提升至 69.0%**。

**值得关注的原因**
世界模型 + VLA 的"规划骨架 + 执行策略"组合正在成为具身智能主流范式（与 Humanoid.guide 总结的 World Model/VLA 分层栈一致）。GeniWorld 用合成数据把 OOD 泛化差距填补近 28 个点，直接回应了联邦关注的"数据基建 > 动作表演"判断——可扩展的策略学习与评估不再依赖昂贵物理环境重建。对 Babylon.js 场景仿真 / 数据合成方向亦有潜在借鉴。

## ④ 阿里发布 Qwen-Robot 具身基础模型系列：Manip + Nav + World 三件套

**事件内容**
8 月 11 日，阿里推出 **Qwen-Robot** 具身 AI 基础模型系列，是 Qwen 家族首个完整具身模型矩阵：
- **Qwen-RobotManip**：VLA 操作模型（"手"）
- **Qwen-RobotNav**：VLN 导航模型（"脚"）
- **Qwen-RobotWorld**：世界模型（"脑"）

三者可独立部署或协同运行，为多样化机器人形态的真实落地提供通用基座。

**值得关注的原因**
大模型厂首次把"手/脚/脑"拆成可组合的基础模型家族，标志具身智能从单点 demo 走向**模块化基座供给**。这与联邦"文档宪法 + 分散注册"的架构哲学异曲同工——能力解耦、按需组合。对评估国产具身大模型生态成熟度、以及未来 MMD/场景编辑器接入外部具身策略接口有风向标意义。
