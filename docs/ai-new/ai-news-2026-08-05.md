## 1. DeepSeek Harness 内测招募演变成「开源 Agent 大摸底」

**事件**：8 月 1 日，DeepSeek 的 Agent Harness 团队负责人崔添翼发文招募 Harness 内测人员，要求申请者参与过开源 Agent 项目的建立与维护并提交 GitHub 仓库。一条招募帖迅速在评论区演变为「开源 Agent 路演」——据开发者统计，截至 8 月 3 日共有 769 位报名者、去重后 712 个开源仓库、合计超 120 万 Stars，覆盖 18 个赛道（个人 Harness、Coding Agent、记忆系统、安全工具、评测框架等）。社区猜测 DeepSeek 正基于内部 Harness 打造一款对标 Claude Code / Codex 的 AI Coding Agent，具备自主规划、工具调用、代码执行，以及 Memory、Repo Awareness 等长周期工作流机制。

**值得关注**：
- 这场"评论区路演"提前暴露了 AI Coding Agent 走向工程化必须持续升级的能力版图：**长时稳定运行、项目上下文与记忆管理、工具调用风险控制、需求到交付的完整闭环**——与联邦 ADR-176（Backend 适配器双实现）、ADR-177（Web Loader 统一路径）强调的"显式状态 + 统一接口"思路同频。
- 120 万 Stars 的体量说明开源 Agent 基础设施正处于爆发前夜，联邦若要做私有化 coding 工作流，生态选型窗口已经打开。

## 2. 贾扬清离职英伟达后携 Intent Lab「Fleet」杀回软件智能体

**事件**：8 月 3 日报道，贾扬清离开英伟达一个月后创立 Intent Lab，推出自主 AI 团队「Fleet」——用户描述开发意图，Fleet 即从系统架构设计、代码开发、基础设施部署到测试、质量验证、性能优化全流程接管。其将软件开发拆解为「理解—设计—协调—构建—验证—演进」六环节，验证环节综合使用形式化证明、集成测试与运行时故障注入。早期成果包括 GLM-5.2 推理引擎提速（Fleet 重设计 TensorRT-LLM 推理性能提升 24%）、一键式数据库创建、经形式化验证的 Agent 文件系统。

**值得关注**：
- 方向清晰：从"代码生成"升级为"系统交付"。这与联邦"小步快跑 + 即时验证"的工程纪律一致——**验证内嵌于构建过程而非事后**才是自治系统的可信前提。
- "形式化验证的 Agent 文件系统"是值得联邦关注的信号：当 Agent 获得写权限，文件系统操作的可证明安全性会成为自治编码的硬约束。

## 3. 阿里 Qwen3.8-Max 宣称完成 10+ 天自主长程编码（自证，未独立审计）

**事件**：8 月 4 日，阿里宣布 Qwen3.8-Max 完成一次持续 10+ 天（技术文档称约 16 天）的长程自主编码运行：从空仓库构建并维护一个"自我演化 Harness"——需求以 GitHub Issue 形式进入，Agent 认领并流转状态、触发端到端测试与 CI、通过则合并 PR、失败则回流 Issue 进入下一轮迭代。技术文档称期间开启并解决 151 个 Issue、产出数百次提交。模型为 2.4T 参数 MoE（95B 激活），计划开放权重（许可细节未定）。

**值得关注**：
- 这是目前公开文档中**最长的前线模型自主编码会话**之一，直接指向"长程多步软件工程工作流如何自我修复"这一核心问题——与第 1 条 DeepSeek 暴露的"长时稳定运行"痛点呼应。
- 关键提醒：所有数字均为阿里**自报、未独立验证**，且社媒"10+ 天"与技术文档"16 天"口径不一。引用时须标注为厂商自证。

## 4. 具身智能迈入「交付时代」：上半年融资 935 亿、全年出货或破 50 万台

**事件**：8 月 5 日，2026 具身智能 50 人论坛夏季峰会披露：上半年国内具身智能融资 322 笔、总额 935 亿元（同比 +137%）；多家机器人公司出货量增速超 50%，仅机器狗品类有单家企业出货破 3 万台，全年整体出货预计 50 万台以上。梅卡曼德提出"智能先于形态"与"一脑多行"（同一套智能系统支撑不同形态机器人，已服务 500+ 客户）；与会判断行业正从"讲故事"迈入"交付时代"，2026 或成规模化量产与商业化爆发元年。

**值得关注**：
- "一脑多行"与联邦"通用逻辑模式收敛（ADR-101）+ 声明式架构（ADR-093）"哲学一致：**统一智能/抽象层屏蔽本体差异**，是具身与软件架构共同收敛到的范式。
- 交付而非 demo 成为主线，意味着仿真训练数据、数字孪生、3D 内容的需求窗口正在放量——对联邦的虚拟仿真资产是潜在机会面。

## 5. 触觉觉醒：具身智能突破"最后一厘米"，VTLA 成新主线

**事件**：8 月 5 日证券时报报道，触觉感知正成为具身智能增长迅猛的细分赛道——今年前 7 个月该领域新增融资超 70 亿元，至少两家新晋独角兽。行业共识从 2025 年的 VLA（视觉—语言—动作）转向 **VTLA（视觉—触觉—语言—动作）**：纯视觉在遮挡、光照折射、易碎/柔性操作场景存在固有短板，触觉深度参与决策成为跳出 Demo、进入真实作业的关键。但触觉数据具不可替代性，数据缺口仍是规模化落地核心瓶颈。

**值得关注**：
- 多模态融合（触觉 + 视觉 + 语言 + 动作）直接对应联邦 ADR-084（虚拟裙骨 Mesh-to-Cloth）、ADR-085（脚部地面跟随）等**物理交互感知**研究方向——柔性操作与力反馈是虚拟仿真必须覆盖的真实交互维度。
- 恺望数据完成超 1 亿元战略融资（松延动力、智元等头部跟投），单月有效数据产出稳定在 10 万小时，印证"数据墙"是具身落地第一瓶颈——数据基建成为确定性"卖铲人"赛道。

## 小结

| 方向 | 今日关键词 | 信号强度 |
|------|-----------|---------|
| AI Coding | DeepSeek Harness 内测、Intent Lab Fleet 系统交付、Qwen3.8-Max 长程自治编码 | 🔴 高 |
| 具身智能 | 交付时代（935 亿融资）、触觉觉醒 VTLA、数据墙瓶颈 | 🔴 高 |
| 交叉点 | 长程自治 + 验证内嵌、统一抽象层（一脑多行）、仿真训练数据需求 | 🟡 中 |

**联邦视角**：今天两条主线在三个层面同频收敛——

1. **长程自治需要验证内嵌**：无论是 Qwen3.8-Max 的自演化 Harness 还是 Fleet 的形式化验证文件系统，可信自治的前提都是"构建即验证"。联邦 CI/binding 不得假设模型一次写对。
2. **统一抽象层是制高点**：具身的"一脑多行"与 AI Coding 的"model-agnostic Harness"都指向同一工程真理——屏蔽底层差异的通用层才是护城河。
3. **数据墙是共同瓶颈**：具身卡在触觉/真实交互数据，coding agent 卡在项目上下文与记忆。联邦的"显式状态沉淀 + 多形态前端"路线，恰好同时回应两条线的痛点。
