## 1. OpenAI 高管：Codex 类 Harness「再火 2-3 个月」，Agent 向云原生基础设施演进

**事件**：OpenAI 产品兼平台总经理 Thibault Sottiaux 公开判断，本地单机 Harness（上下文管理、工具调用、状态持久化、环境隔离、异常恢复套件）将在 2-3 个月内成为「原始工具」。下一代高自主、长时推理模型会以「本地轻指挥、云端重执行」形态运行——任务丢进云端隔离沙箱自治，本地只做指挥控制与 Diff/日志回流。

**三大物理瓶颈**：
- 算力/内存：并发 20 子任务时本地 CPU、内存、沙箱资源瞬间爆满。
- 长任务不可关机：任务跑数小时至数天，要求笔记本不关机不合盖，反人性。
- 上下文与工具链并行爆炸：极长上下文 + 高并发推理下，本地难做上下文压缩、状态同步与集中日志。

**值得关注**：印证我们城邦的架构预判——`main.ts` 已拆分（ADR-102）、逻辑收敛到 `uiState` 持久化链（ADR-103），本质也是在把本地「重执行」往可编排、可恢复的系统层迁移。E2B / Daytona / Modal 等云微沙箱正在成为新基础设施。对 Coding Agent 而言，竞争维度正从「模型推理强」转向「Harness 释放模型潜力的程度」。

## 2. NVIDIA 开源 NOOA：把 AI 智能体压成「一个 Python 类」，253 行拿下 SWE-bench 82.2%

**事件**：NVIDIA Labs 发布 **NOOA（NVIDIA Object-Oriented Agents）**，Apache 2.0，仓库 `NVIDIA-NeMo/labs-OO-Agents`，论文 arXiv 2607.20709。核心映射极简：
- 类 → 智能体
- 方法 → 模型可执行的动作
- 字段 → 智能体状态
- docstring → 提示词
- 类型注解 → 运行时强制契约

方法体写 `...` 即由 LLM 循环补全；写普通代码则保持确定性 Python 执行。**253 行示例智能体 + GPT-5.5 xhigh** 在 SWE-bench Verified 达 **82.2%**（超 OpenCode 78.6%、PI 78.2%）。

**值得关注**：
- 与 LangGraph 图编排对比：NOOA 样板更少、贴近原生 Python 开发；代价是复杂流程隐式行为难追踪，调试依赖运行时可视化。
- 安全警示：类型注解成运行时契约、方法体成 LLM 决策循环时，提示注入可沿工具调用渗透智能体状态——需配严格输入校验/输出过滤/权限边界。
- 对联邦启示：模型无关 + 极简抽象的取向，与我们「通用逻辑模式第二波收敛」（ADR-101）的「少样板、强类型约束」思路同频。

## 3. 宇树科技 8/10 科创板申购，「身体」不再护城河、「大脑」成新竞速点

**事件**：宇树科技 8 月 10 日科创板开启申购，发行价 **150.80 元/股**，对应市值 **609.9 亿元**，A 股「人形机器人第一股」登场。拟募资约 42 亿元，其中**模型研发 20.22 亿元首次超过本体研发 11.1 亿元**。行业宏观面：截至 8/8 中国机器人领域今年融资 **1217 亿元**（超 2025 全年约 67%）；港股 51 家具身智能企业排队。

**关键趋势**：
- 竞争从「秀肌肉」（双足/后空翻 Demo）转向「比智力」，上半年超一半资金涌向「大脑派」，本体厂商拿钱不到 20%。
- 路线分化：工业产线/物流仓储/商业服务 vs 消费端家庭陪伴。
- 未来竞争维度：特定场景**稳定交付能力、批量一致性、供应链降本、综合运维**。

**值得关注**：与 Coding 侧「Harness 即护城河」镜像——具身侧「大脑」（VLA/世界模型）正取代硬件成为估值核心。纯概念、无验证商业闭环的企业将加速出清。

## 4. 灵巧手成 2026 最热赛道：中科慧思发布 37 自由度产品，「有手无脑」仍是核心瓶颈

**事件**：蓝思科技 + 中科慧灵 + 华夏投资成立**中科慧思具身智能**，发布 L1/D1/M1 三款灵巧手 + 预发布 F 系列绳驱仿生手（最高 37 关节自由度），落户湘江新区，拟建全国最大灵巧手技能训练场与数采中心。行业测算：2025 中国灵巧手出货近 2 万只，2026 将达近 7 万只（约 3.7 倍增速）。

**四大痛点**：
1. 贵而不稳：高自由度触觉手市价十几万～上百万，工业连续作业寿命仅数周～两三月。
2. 集成难：轻量化/大负载/高精度/强感知相互牵制。
3. **有手无脑**：现有 VLA 模型无法驱动 20-30 自由度手真正干活。
4. 连杆/腱绳/直驱三线未收敛。

**值得关注**：数据瓶颈是深层约束——开源灵巧手精细操作真实数据仅「几万条」，差文本语料/整机轨迹好几个数量级。「硬件定义数据上限，数据定义硬件价值」的双飞轮模式，是具身智能从 Demo 到规模化的典型解法。

## 5. 具身智能抢滩线下商圈：商业前哨还是流量泡沫？

**事件**：宇树、智元、启元世界等头部玩家集体落子核心商圈（南京西路、王府井、光谷、深圳）。两条路线成型：①品牌直营+联合零售（宇树直营店进重奢商场，联合京东覆盖 8 千～17 万价格带）；②集合店（陶朱新造局聚 200+ 款产品，光谷 7S 店 2 个月客流 1.8 万、销售额约 61.5 万）。

**关键信号**：
- 宇树 2025 前三季度人形收入：科研教育 73.6%、商业消费 17.39%、行业应用 9.01%——**B 端仍是绝对主力**，门店是商业化试验场。
- 渠道逻辑：向手机学零售效率，向汽车学高客单价转化（试驾式深度体验）。
- 门店三重功能：获客、验证线下商业模型、跑通「体验→交付→售后」闭环。

**值得关注**：线下门店是「先用少数核心店验证用户画像/价格带/话术，再复制渠道」的样板间。对联邦的隐喻——这恰似我们「小步快跑 + 即时验证」：先建可信交付闭环，再谈规模复制。
