## 1. Google DeepMind 发布 Gemini Robotics 2 —— 定义"机器人操作系统"

**事件**：7 月 30 日，Google DeepMind 发布 Gemini Robotics 2 模型家族，包含三个组件：
- **Gemini Robotics 2（VLA）**：首个端到端控制完整人形机器人全部自由度的视觉-语言-动作模型，从双腿到手指的全身运动统一由单一模型权重驱动，已在 Apollo 2、Franka Duo 等多本体验证。
- **Gemini Robotics ER 2（具身推理）**：负责高层规划、视频流实时进度追踪、多机器人协作，关键帧识别准确率近 90%。
- **Gemini Robotics On-Device 2**：本地离线 VLA，仅需约 200 条样本 / 数小时即可适配新本体。

谷歌采取"不卖本体、只卖大脑"的平台策略，开放推理层 API，并提出"一个大脑，适用于任何机器人"的路线。同步推出 ASIMOV-Agentic 安全基准。

**值得关注**：
- 弥合了机器人领域两个关键断层——「行走/操作控制器分离」与「跨硬件迁移门槛」，对 Babylon.js 这类 3D 引擎做机器人仿真 / 数字孪生有直接的模型层参考意义。
- 平台化打法与联邦的"通用逻辑模式收敛"（ADR-101）思路相通：用统一抽象层屏蔽底层差异。

## 2. Claude Code 仍居 AI Coding 主导，但 OpenAI Codex 反攻开启

**事件**：
- 8 月 2 日多家媒体报道，Anthropic 的 Claude Code 虽因切换按量计费导致成本上涨（人均月成本中位数从 1 月 $69 升至 6 月 $219），仍难撼动其领先地位，大量企业嵌入内部流程后迁移成本高。
- OpenAI 方面，Codex 周活已超 500 万，5 月推出从 Claude Code 迁移工具后 10 天获超 10 万注册；布罗克曼重整产品线、引入首位 CRO，并与亚马逊达成 500 亿美元投资 + AWS 分发协议。
- 市场同时呈现碎片化：企业按任务将 Claude Code / Codex / 开源模型（GLM-5.2、Kimi-K2.5 等）混合路由，开放权重模型 token 占比显著上升。

**值得关注**：
- AI Coding 竞争焦点已从"模型能力"转向"工作台产品 + 渠道 + 价格"的完整商业系统——对联邦的 AI 辅助开发流程设计有借鉴价值。
- 成本驱动的开源模型渗透，意味着本地化 / 私有化 coding agent 将成为重要变量。

## 3. 腾讯 CodeBuddy NPC 实现"需求到 PR"全流程自主交付

**事件**：据边缘算力产业报道，腾讯云 CodeBuddy NPC 已实现从需求拆解到 PR 交付的全流程自主完成，Token 消耗降低 90%。

**值得关注**：
- "独立交付"是 AI Coding 从"辅助"走向"自治"的关键拐点，与 Codex "Software Engineering Agent" 定位一致。
- Token 成本两个数量级下降，意味着中小团队可负担的完整 PR 级自动化已在临界点。

## 4. 具身智能进入"机器人超级月"——商业化验证集中爆发

**事件**：
- 8 月被业内称为"机器人超级月"：宇树科技冲刺科创板 IPO、比亚迪首款自研人形机器人亮相"迪空间"、北京世界机器人大会集中展示。
- 竞争焦点从"能不能做出来"转向"能不能创造价值"——工厂、门店、物流等真实场景落地与降本成为规模化关键。
- 供应链侧：雷赛智能定增逾 11 亿元扩产人形机器人核心零部件，无框力矩电机在手订单突破 100 万台；山东邹城建成全省最大工业机器人基地。
- 政策侧：美国 FCC 将"外国先进机器人设备"列入管控清单，宇树在售型号暂不受影响但新型号或受限，倒逼企业转向欧洲 / 中东 / 东南亚市场。

**值得关注**：
- 具身智能从样机走向产品的"中试"环节成为瓶颈——杭州国家级中试基地（全国唯一）探营报道揭示：仿真到现实的落差、训练数据稀缺、保险与责任划分是核心堵点。
- 对联邦而言，"机器人超级月"意味着 3D 内容 / 虚拟仿真训练数据的需求窗口正在打开。

## 5. 全尺寸人形机器人全国决赛首次"全程无遥操"

**事件**：8 月 1 日，第二十八届中国机器人及人工智能大赛人形机器人专项赛全国决赛在北京开幕，213 支队伍、350 多台人形机器人参赛。全尺寸组首次采用全程无遥操模式，复现高危巡检、产线上下料、零部件分拣等真实工业场景，要求机器人在 50 分钟内基于自身传感器自主完成斜坡攀爬、上下楼梯、穿越崎岖地形等任务。

**值得关注**：
- "无遥操 + 真实工业场景"是具身智能脱离演示、进入实用的重要信号，与联邦 ADR-084（虚拟裙骨）、ADR-085（脚部地面跟随）等物理交互研究方向形成产业对照。
- 高校大规模参赛意味着具身智能人才供给正在规模化，长期利好整个赛道。
