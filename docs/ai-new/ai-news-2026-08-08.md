## 1. Meta 发布首款 AI 编程智能体 Muse Code（8/6）

- **事件**：Meta 推出终端式编程 Agent **Muse Code**（测试版），由 Muse Spark 1.2 模型驱动，单命令安装。核心工程特性：① 本地事件日志作为唯一可信源，支持**崩溃恢复与精确重放**，可连续运行 24 小时；② 常驻异步后台子 Agent 并行处理，降低长任务对人工引导的依赖；③ 内置 `/plan`、`/grill` 等技能，计划需审批、反复压力测试后执行。定价走低价路线，"贡献者档"甚至不到按量付费的 1/10（需同意用数据改进模型），同时接受企业"零数据保留"请求。
- **值得关注**：Meta 正式入局 coding agent 赛道，与 OpenAI Codex、Anthropic Claude Code 正面竞争。**"崩溃可恢复 + 长周期任务"** 是差异化卖点——对联邦这种需要跑长时重构/大仓分析的场景有参考价值。基准上 Muse Code 在 Terminal-Bench 2.1 得 82.9%，略超 Codex（81.8%）但低于 Claude Code/Opus 5（86.7%），性能非最强、靠可靠性与性价比切入。

## 2. Anthropic 8/14 起为 Claude Code 默认启用 Auto Mode（8/8）

- **事件**：Anthropic 宣布 8 月 14 日起，Pro/Max/Team 订阅的 Claude Code 默认权限模式切换为 **Auto Mode**。该模式用独立 AI 分类器实时评估每次工具调用与 Shell 命令，放行安全操作、自动拦截破坏性/不可逆/越权行为。实测：传统人工审批仅识别 13.6% 危险命令，Auto Mode 提升至 **89%**；提示注入评估中 Fable 5 / Opus 5 / Sonnet 5 自动模式拦截率 0/720 次攻击成功。分类器额外 token 费用即日起对 Pro/Max/Team 免收。
- **值得关注**：coding agent 从"默认需人工逐条审批"走向"智能护栏默认放行"，是**自治与安全的平衡点**关键演进。对联邦的启示：AI 代理要长时后台运行，必须有一层可靠的命令级安全分类器，而非简单 bypass 权限。

## 3. Claude Code v2.1.224：自托管 Runner + 跨会话消息（8/7）

- **事件**：Claude Code 发布功能更新——**self-hosted runners**（Team/Enterprise）：UI 与计算分离，会话可在企业内网自有机器上执行，满足数据驻留与内网访问需求；**跨会话 SendMessage/ListAgents**（macOS/Linux）：不同机器的 Code 会话可互相发现与通信，发往 bypassPermissions 会话的消息会暂挂待用户批准；**archive plugin source**：支持从单 zip + SHA-256 钉选安装插件，无需 git/npm，适配封闭网络。
- **值得关注**：自托管 Runner 直击企业合规痛点——这恰是联邦若要在内部代码库大规模部署 agent 时绕不开的架构。跨会话消息则预示"多 agent 协作"开始成为终端工具的一等公民。

## 4. Figure 03 自主爬梯：loco-manipulation 首次完整形态（8/5–8/6）

- **事件**：Figure AI 创始人 Brett Adcock 发布视频，Figure 03 在实验室环境**无遥控、无预设动作序列**自主攀爬工业梯子，将实时视觉伺服（眼）、抓握扶手（手）、动态平衡（腿）三套控制回路耦合进同一连续动作。官方披露量产已从每天 1 台提升至每小时 1 台，累计交付超 350 台，估值约 390 亿美元。
- **值得关注**：具身圈视爬梯为标志性事件，因为**移动操作耦合（loco-manipulation）第一次以完整形态出现**——此前演示多为走路/抓取单能力展示。三个限定需冷静看待：① 视频未经独立验证、未披露成功率；② 实验室能力≠工厂能力；③ 演示与量产体系须合看，媒体易把演示当验收。对联邦的映射：多模态感知-控制回路同步，正是 3D 场景编辑器里"手-眼-运动"协同难题的物理世界镜像。

## 5. 具身智能告别"炫技"：量产与商业化成主线（8/8）

- **事件**：行业综述指出今年关键词只剩"量产"。上半年国内具身智能/机器人融资总额 **460 亿元**（226 家企业、288 起）。IDC 数据：2025 中国人形机器人出货 1.44 万台（占全球 84.7%），预计 2026 超 6.25 万台。专家认为真正商业化需闯三关：**工程可靠性、经济可行性（ROI）、可持续运营与服务**。硬件预计 2028–2029 初步稳定，但软件/生态成熟度落后硬件 3–5 年。越疆 8/5 发布全球首款"具身全栖"人形机器人 DOBOT LUMO（情绪感知+主动空间行动）；小米 8/5 开源具身基础模型 Xiaomi-Robotics-1（MoE 480 亿参数、激活约 50 亿，可端侧运行）。
- **值得关注**：赛道从"百模大战"转向"订单/交付/回款/复购"硬指标。开源基础模型（小米、DeepMind RT、英伟达 GR00T、智元、宇树）正加速生态竞争——**"大脑"技术民主化**降低研发门槛，但真实场景数据（传感器到执行器闭环）仍是核心壁垒，工厂/仓库成为未来竞争力的数据资产。
