## ① 新终端基准 Terminal-Bench 3.0：头部 Agent 从 84% 暴跌至 34%

**事件内容**
开发者社区推出持续版本化的终端 Agent 评测基准（Terminal-Bench 3.0）。其关键设计是：任务结束后从独立 verifier 容器中下载工件、重新评分，切断 Agent 直接改测试"奖励黑客"的路径。在该基准下，此前在旧版 2.1 上得分约 84% 的头部 Agent 跌至 34%。成本数据同样值得注意：GPT-5.6 Sol 与 Fable 5 通过率接近，但 Sol 便宜约 40%、token 消耗少约 50%。

**值得关注的原因**
- 暴露旧基准普遍存在的"奖励黑客"虚高问题——评分含金量首次被严格隔离验证。
- 重申一个已被反复验证的论断：**分数衡量的是"模型 × Harness"组合**，单次 harness 改动即可挪动 20 个任务。这与联邦 ADR-238 的"桥接解耦、分散注册"路线高度呼应——把 Agent 能力与执行层解耦，正是产业正在走的方向。
- 成本-通过率前沿首次成为可读信号，工程选型从"谁最强"转向"谁最划算"。

**来源**：Dev.to / Ground Truth（2026-08-14 前后）；Terminal-Bench 排行榜 mirror（DevThrottle，2026-08-14 更新）

## ② Vero 基准：AI Agent 仍无法在仓库级产出"可机器验证"的软件

**事件内容**
UC Berkeley 等团队发布 **Vero**（arXiv: 2608.13522），首个在**仓库级**同时评估"实现 + 形式化证明"的基准。包含 43 个跨模块真实仓库实例（Python / Dafny / Verus / Coq），覆盖密码协议到分布式系统。最强前沿 coding Agent 配置仅能完整解决 43 题中的 27 题，在最难仓库上零通过。

**值得关注的原因**
- 直指 coding Agent 的核心短板：**生成代码不提供正确性保证**。Vero 把"可信软件合成"从单函数推向多模块协同，是当前最硬核的进度标尺。
- 对联邦的启示：我们日常的"信任但验证"纪律（读源码/git log/结构核实后再更新 ADR 状态）与 Vero 的哲学一致——AI 产出必须可被独立验证，而非被摘要记忆带偏。
- 形式化验证 + Agent 的交叉地带，是下一个高价值工程方向。

**来源**：arXiv 2608.13522 / Daily arXiv Digest 2026-08-14

## ③ ω-0 隐空间预测世界动作模型：人形机器人"边走边做"成功率 81.8%

**事件内容**
南洋理工、北大、港科大（广州）、智源研究院联合发布 **ω-0**（Omega-0）隐空间预测世界动作模型。核心架构不再预测未来像素，而是预测**未来视觉特征**，由扩散 Transformer 直接生成全身动作。在 11 类真实居家"移动中操作"任务上，Ego 第一视角 79.1%、全场景 Omni 81.8%，显著优于 π-0.5、EgoVLA、GR00T-N1.7、psi-0。团队同步开源 **ω-HOME** 数据集（40.3 小时、4827 条轨迹、24 类任务）。

**值得关注的原因**
- 解决具身智能长期痛点：**移动与操作割裂**。传统"先站定再操作"在家庭连续作业中必然中断/失衡；ω-0 将全身视为统一动作系统，是 loco-manipulation 的关键路线。
- "预测视觉特征而非像素"的范式，与 NVIDIA WAM（8/4 发布，已被 8/8 报过）形成互补印证——世界模型正从"视频生成"转向"隐空间物理推演"，具身路线收敛信号增强。
- 数据集开源降低行业对人工示范的依赖，呼应联邦观察到的"数据基建 > 动作表演"主线。

**来源**：Pandaily / ITBear（2026-08-11–13）；NTU-PKU-BAAI 联合发布

## ④ 具身路线大分流：WAIC 后"世界模型 + VLA"成主流混搭，标签之争退场

**事件内容**
AI 前线 8/13 报道：经历半年 VLA vs 世界模型路线骂战，产业进入"落地祛魅"新阶段。刚结束的 WAIC 上，机器人展品从"能动演示"转为围绕 3C 电子、汽车制造、仓储物流的真实场景应用。头部厂商悄然"混搭"——今年展示模型从去年以 VLA 为主，变为"世界模型 + VLA"占绝大多数。智平方（郭彦东）、星海图（高继扬）均明确"两者非对立、终将融合"；VLA 概念共同开创者 Generalist AI 甚至公开"抛弃"标签。

**值得关注的原因**
- 路线之争从"谁对"转为"机器人到底动起来没有"——**商业验收取代技术站队**，与联邦"外科手术式定点修改、保留周围成果、反对推倒重来"的工程价值观同构。
- 对联邦启示：模块化可组合（VLA 实时操作 + WAM 前瞻推演）与 ADR-238 分散注册、"桥接而非聚合"的解耦哲学一致——不要把正确路线押注在单一范式上，用桥接层容纳多路线并存。
- 自变量 WALL-B"世界统一模型"（8/13 实测分拣 1816 件/小时、成本仅 Figure 三成）是"抛弃分治式 VLA"的极端样本，与 ω-0 形成"统一 vs 融合"两种范式对照。

**来源**：AI 前线 / 量子位（2026-08-13）；具身之家实测报道
