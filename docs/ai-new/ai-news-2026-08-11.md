## 1. Google DeepMind 发布 Gemini Robotics 2（全身控制 VLA 系列）

**事件**：8 月初 DeepMind 发布 Gemini Robotics 2 模型家族，含三款模型——主力 VLA（端到端全身控制，从脚趾到指尖）、ER 2（具身推理/多机协作规划）、On-Device 2（端侧 <200 样本快速适配）。首次实现**单一模型权重驱动异构机器人本体**（Apptronik Apollo 2 + 双臂 Franka Duo），并完成"跨房间行走 + 抓取 + 放置"全流程。同步推出 **ASIMOV-Agentic 安全基准**（拒绝不安全工具调用、临近人体主动停机）。

**为何关注**：具身"大脑"的标准化平台之争正式开打——DeepMind 明确摆出"机器人界安卓"姿态（通用智能层 + 跨硬件授权）。值得盯两点：① 当前成功率仍有限（桌面拾取 68.4%、地面 45.7%），"全身闭环打通但离稳定可靠有差距"；② 安全基准前置到模型发布，呼应 coding agent 侧的"harness 即信任边界"命题——两域同源。

## 2. 小米开源 Xiaomi-Robotics-1 全身 VLA 基座模型

**事件**：8 月 5 日小米在 Hugging Face / GitHub 开源次世代具身基座模型 Xiaomi-Robotics-1，放出**完整后训练→部署 pipeline + 评测代码 + 权重**。预训练基于 10 万小时 UMI 轨迹 + 1 万小时跨本体后训练；RoboCasa365 成功率 57.4%、RoboDojo 20.07%。定位"开箱即用"的 VLA，意图把机器人创新重心从硬件转向可插拔神经软件。

**为何关注**：与 DeepMind 闭源智能层打法形成对照——小米走"开源权重 + 标准化运动控制基线"路线，直接压低行业准入门槛。对中小团队意味着不必重采专有轨迹数据集，可直部自有本体做 fine-tune。这是具身侧"开源基座 vs 闭源平台"双轨并行的关键信号。

## 3. Black Hat 2026：一个 GitHub Issue 攻破三大 Coding Agent（CVSS 10.0）

**事件**：Novee Security 在 Black Hat USA（8/5）现场演示——**零仓库权限的匿名 GitHub Issue 即可触达 CI 密钥**。三处落地：
- **Gemini CLI** CVE-2026-12537，**CVSS v4 10.0**：sandbox 初始化前即 RCE，`--yolo` 模式 allowlist 注册后不执行。
- **Claude Code** CVE-2026-54316（CVSS v3.1 9.1）：命令校验器剥离单引号文本导致校验绕过，借 Hugging Face 公开下载计数器作隐蔽信道逐字符外泄 API key；修复于 2.1.163。
- **OpenAI Codex**：无 CVE，多 pass 架构下首 agent 写入 `AGENTS.md` 被次 agent 当作可信指令加载（OpenAI 认定 sandbox 按预期工作）。

**为何关注**：根因不在模型，而在 **harness 层**（校验器/沙箱边界/进程隔离失败）。研究员原话："The harness is the code between the model and the real world." 与 7 月末判断完全吻合——**coding 与具身的信任边界本质同源，系统工程 > 裸模型能力**。落地动作：升级 Claude Code ≥2.1.163、Gemini CLI ≥0.39.1；审计所有外部可触发 workflow；agent 阶段间隔离 workspace 与身份。

## 4. Y Combinator 开源 QM 多 Agent Harness（MIT）

**事件**：7/31 YC 宣布开源内部使用的 **QM**——面向"整家公司而非单用户"的多 Agent 编排 harness，云原生、原生 Slack/Web 接口、MIT 许可。核心**模型无关**：同一编排循环可跑 Pi / OpenCode / Codex / Claude Code。

**为何关注**：继续印证 7 月主线——**差异化发生在模型外围的 Harness 层**（记忆、权限、沙箱），而非模型本身。QM 把"企业级多 agent 协作"从闭源内部工具变为公共基建，等于给 coding agent 的"操作系统层"补了一块关键拼图。

## 5. 宇树科技科创板 IPO 询价 + 8 月机器人"超级月"产业共振

**事件**：8 月机器人赛道技术/资本/会议/政策多维共振：宇树科技启动科创板 IPO 询价（拟募 42 亿、估值约 420 亿，最快 8 月底登陆）；8/12-14 上海具身智能产业大会、8/19-23 世界机器人大会（北京，300+ 企业、150+ 首发）、8/22-26 世界人形机器人运动会；比亚迪首款人形机器人 8 月亮相；摩根士丹利上调 2026 中国出货预测至 5 万台（原 2.8 万）。
