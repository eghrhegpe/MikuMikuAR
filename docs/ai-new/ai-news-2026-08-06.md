## 1. Meta 发布 Muse Code 编程智能体（coding，价格战开打）

- **事件**：8/5 扎克伯格亲自官宣，Meta 首款 AI 编程智能体 Muse Code 测试版上线，由超级智能实验室（Alexandr Wang 主导）推出。基于终端，搭载专为代码优化的 **Muse Spark 1.2** 模型，一键安装，可自主规划变更、写码、验证，并自旋多个持久化子 Agent 并行处理大仓库任务。
- **关键数据**：
  - 跑分居中：TerminalBench 2.1 得 82.9%（超 Codex 81.8%、Grok Build 81.6%，不及 Claude Code 86.7%）；DeepSWE 1.1 得 59.3%（落后 Claude Code 65.0%、Codex 64.8%）。
  - **定价仅竞品约 1/10**：按量付费输入 $1.25 / 百万 token、输出 $4.25 / 百万 token；「贡献者版」再低 10 倍以上（需同意用于改进模型）；企业可申请「零数据留存」。
  - 工程特性：支持 24 小时长任务、崩溃可恢复。
- **值得关注**：coding 赛道正式进入价格战；Meta 明确以「可靠性 + 极限性价比」而非纯性能差异化。对团队选型而言，中端场景多了低成本可选项，但企业敏感数据须走零数据留存条款。

## 2. Agent 框架安全集体爆雷：Langflow CVE-2026-9198 遭活跃利用（coding，安全）

- **事件**：IBM 旗下低代码 Agent 构建平台 Langflow 出现 **CVSS 9.8 无认证 RCE**，CISA 于 8/4–5 列入 KEV 目录并确认已有活跃利用。漏洞链：`/api/v1/auto_login` 在默认部署下给任意网络调用方发放 SUPERUSER token，叠加 `/api/v1/validate/code` 用 `exec()` 执行任意 Python，两请求即可拿下整台主机。影响版本 1.0.0–1.10.0，修复于 1.10.1（现行 1.11.2）。
- **同批风险**：Check Point 另披露 LangChain、LangGraph、CrewAI、AutoGen、Microsoft Agent Framework、Google ADK 等 11 个 Agent 框架的提示越权漏洞（提示内容可跨入框架可信逻辑）。
- **值得关注**：Agent 框架须按生产级中间件对待——补丁 SLA、网络隔离、运行时监控，不能只防 prompt injection。本月「自治可控」命题在信任基建层面被硬验证。

## 3. Claude Opus 5 + Claude Code 2.1.223 安全收口（coding，性价比基线再重构）

- **事件**：Anthropic 7/24 发布 **Claude Opus 5**（Claude Code 2.1.219 起默认 Opus 模型），8/6 又推 2.1.223 收口多项安全缺陷。
- **关键数据**：
  - Opus 5：原生 1M token 上下文、默认开启思考、价格持平 Opus 4.8（$5/$25 每百万），SWE-bench Pro 79.2%（较 4.8 的 69.2% ↑10pt），ARC-AGI-3 约为次优模型 3 倍，Frontier-Bench v0.1 43.3% 居首。
  - 2.1.223 修复：Bash 权限绕过（crafted command 隐藏自身绕过权限检查）、worktree 隔离覆盖文件编辑与 Bash、marketplace owner 通配（`owner/*`）。
- **值得关注**：高端 coding 模型性价比基线再重构；工具链开始系统性补齐「自治可控」信任基建（网络严格白名单、目录钩子、CI 静默 MCP 失败可见化）。

## 4. Figure 03 无遥控自主爬工业梯（具身，验收季警钟）

- **事件**：8/6 Figure 创始人 Brett Adcock 发布视频，Figure 03 在实验室环境**无遥控、无人工协助、无预设动作序列**自主攀爬工业梯子。依托 Helix 02 三层架构（System 2 语义理解 ~1Hz 分解动作序列）。
- **关键定性**：这是首个把「眼（实时视觉伺服）+ 手（抓握扶手）+ 腿（动态平衡攀爬）」耦合进同一动态任务的演示，即 **loco-manipulation（移动操作耦合）完整形态**——过去十年演示基本是「走路归走路、抓取归抓取」分开做。
- **三个必要限定**：
  1. 视频未经独立验证，未披露成功率/测试条件/失败数据，动作明显慢于人类；
  2. 爬梯子是实验室能力，非工厂能力；
  3. 演示（爬梯子）与体系（时产 1 台、累计交付 350+ 台）须合看，单看任一面都会误读。
- **值得关注**：2026 人形机器人最大叙事风险是「媒体把演示当验收」。对联邦启示：MMD 查看器/场景编辑器的「演示可用性」与「量产稳定性」须分开评估。

## 5. 世界模型走俏 + HOST 框架开源（具身，数据闭环新范式）

- **事件 A（世界模型）**：李飞飞 World Labs 7/28 发布技术博客《Building Worlds That Train Robots》，完成对仿真初创 SceniX 收购后，打通「真实任务—仿真世界—真实机器人」闭环，主张机器人策略训练数据可完全来自仿真，绕开真机数据成本高、周期长、长尾覆盖不足之困。
- **事件 B（视频直学）**：国内自变量机器人 8/3 开源 **HOST**（Human-to-robot One-Shot Skill Acquisition）。真实四足机器人仅凭一段手机随手拍人类操作视频（如煎蛋、叠毛巾），**未接触任何该任务训练数据**，10 分钟内首次执行成功、成功率 62%（比最强零样本基线 +45pt，学习效率约为 Pi-0.5+微调的 500 倍，数据需求减 50×）。核心思路：MoT 双核「视觉大脑锚定任务里程碑 + 动作大脑倒推下一帧预期画面所需的动作」，即「预测画面而非翻译动作」。
- **值得关注**：具身数据闭环从「堆真机数据 / 模仿学习」走向「仿真生成 + 视频预测」，与 coding Agent 的「上下文 / Harness 层收敛」命题同源——都在用系统工程绕开数据/上下文瓶颈。
