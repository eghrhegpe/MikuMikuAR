## 1. [AI coding] 上下文工程成 Coding Agent 失败第一根因

**事件**：7 月社区研究集中指出，多数 coding agent 在真实仓库失效并非模型能力不行，而是**上下文供给错误**。Chroma 测 18 个前沿模型随上下文变长全面退化；ETH Zurich 发现自动生成超长 `CLAUDE.md` 使任务成功率降约 3%、成本涨 20%+；Sourcegraph CodeScaleBench 显示「给对工具」比「给长上下文」更关键。

**值得关注**：联邦长期把 `AGENTS.md` / `docs/knowledge/` 作为上下文入口，此结论验证了「检索式知识卡 + 精准 source_files 跳转」优于「一次性灌入长文档」的路线。应避免让 agent 通读全仓库，改为按 `docs/knowledge/README.md` 索引 + grep 卡正文锁定符号。

**来源**：腾讯新闻 / 星屿智享 / AI 工程师（2026-07-24）

## 2. [AI coding] 多 Agent「项目失忆」催生跨会话记忆层（Deja-vu / AGENTS.md 三层架构）

**事件**：7 月 24 日文章指出长期使用多个 coding agent 时项目持续「失忆」，关键经验锁在各自信任里。开源项目 **Deja-vu** 通过索引 Claude Code / Codex / Cursor 本地会话实现跨 Agent 检索与 handoff，并提出 `AGENTS.md` / `DECISIONS.md` / `KNOWN_ISSUES.md` / `RUNBOOK.md` 三层记忆架构。

**值得关注**：联邦已具备 `AGENTS.md` + `.workbuddy/memory/` 双层记忆（项目级 daily log + MEMORY.md），与文中范式高度重合。可借鉴 `DECISIONS.md` / `RUNBOOK.md` 思路，把「已拍板的架构决策」与「可交接的运行手册」从散落对话中显式沉淀，强化多 agent 并发下的状态连续性。

**来源**：腾讯新闻 / AI 工程师（2026-07-24）

## 3. [AI coding] Claude Code 2.1.210 修复 worktree 隔离与 prompt-injection 安全缺陷

**事件**：7 月 14–19 日 Claude Code 一周内发 8 个补丁（2.1.208→2.1.215）。**2.1.210** 修复关键数据安全问题：`worktree` 子代理曾可对主仓库 checkout 执行 git 变更命令（而非其隔离 worktree），并加固 Agent 工具防范子代理读取内容导致的间接 prompt injection；2.1.208 新增屏幕阅读器模式与企业级 `CLAUDE_CODE_PROCESS_WRAPPER` 钩子。

**值得关注**：联邦采用「多写者 / 多智能体并发模式 + 独立 worktree / 分支 + 文件认领注册表」的工程纪律，与此修复直指同一风险面。若联邦引入并行后台 agent，应确认 runtime 已 ≥ 2.1.210，避免隔离失效导致的工作树污染；同时对「子代理读取外部内容」保持注入警惕。

**来源**：dreaming.press / gradually.ai Changelog（2026-07-20–25）

## 4. [具身智能] 智元机器人启动赴港上市，2025 通用人形出货超 5100 台全球第一

## 5. [具身智能] 越疆人形机器人完成全球产业现场大规模交付，「一脑多体」集群调度落地

**事件**：7 月 24 日，越疆科技披露大批人形机器人已部署于全球多个真实产业现场，持续开展上下料、高精度分拣、精细装配、成品回流等任务验证。其将协作机器人十余年的运动控制 / 力控 / 轨迹规划能力迁移至人形上肢，搭载自研「空弈 DobotWAM」具身大模型，构建「一脑多体」智能系统对多机型做任务拆解与集群调度。

**值得关注**：越疆路径（从真实制造需求反推机器人能力、把现场反馈导入研发制造闭环）与联邦「先做通再泛化、避免推倒重来」的工程哲学一致。「一脑多体」概念也呼应联邦「统一后端适配器（ADR-176）+ Web/桌面统一路径（ADR-177）」的抽象思路——同一智能核心驱动多种形态前端。

**来源**：深圳新闻网（2026-07-24）
