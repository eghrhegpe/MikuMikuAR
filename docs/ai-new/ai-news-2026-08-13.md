# AI 日报 · 2026-08-13

> 选题方向：AI Coding + 具身智能
> 主线判断：两域同步进入「治理博弈期」——能力竞赛退场，系统工程 + 信任基建登台。与联邦 ADR-238 桥接层 / Harness 化拆分哲学同源。

---

## 1. Agent Plugins 打包标准出炉：Amazon / Cursor / Microsoft / OpenAI / Vercel 联合

- **事件**：五大厂联合推出 Agent Plugins 打包标准，用 `plugin.json` 统一 Agent Skills 与 MCP servers 的分发格式，终结「每个平台重写一遍扩展」的局面。
- **为何关注**：编码 Agent 生态从「各自为政」走向「分发标准化」。对联邦而言，Skill / 桥接层的封装粒度若对齐该标准，未来可低成本复用外部能力，减少 core→menus 这类耦合反复出现。这是「能力封装层 = 新包管理器」趋势的正式落地。

## 2. AI 编码预算失控：Replit / Kilo Code / Symbotic 改用「每任务成本」

- **事件**：VentureBeat 深度报道三家公司披露编码 Agent 预算失控（工程师单日 AI 账单达 600 美元），现统一改为跟踪「每任务成本」而非原始花费。另一分析指出 Claude Opus 5 最便宜档位解决的任务数反多于最贵档位，成本仅 1/3。
- **为何关注**：选型逻辑从「跑分导向」转向「单位任务成本导向」。这要求新的可观测性指标——而非新模型。联邦的 commit 前 tsc + cycles + tests 验证链本质是「任务级成本护栏」的工程实践，与行业收敛方向一致。

## 3. DeepSeek V4 Flash 0731：13B 本地可部署，0.09 美元 / 百万 tokens

- **事件**：8 月 7 日发布，模型压缩至 13B 参数级，M2 MacBook 推理 80 tokens/s，消费级显卡可本地部署，API 价 0.09 美元 / 百万 tokens。
- **为何关注**：编码 Agent 从「云端托管」回归「本地优先（Local-First）」。代码不出本机 + 合规可控，对政企 / 金融场景是默认选项。联邦若评估离线编码工作流，此模型是低成本底座候选。

## 4. 具身智能「可靠性税」：Optimus / Walker S 进厂实测 + 工信部三级安全认证

- **事件**：8 月 6 日特斯拉 Optimus 二代在上海超级工厂 Pack 产线连续 72 小时无干预装配（成功率 94.3%，MTTR 4.2 分钟）；优必选 Walker S 在蔚来合肥工厂获「量产准入资格」。8 月 7 日工信部联合市场监管总局发布《人形机器人工业应用场景安全要求与测试方法》（征求意见稿），首提 L1/L2/L3 三级安全认证。
- **为何关注**：具身竞争维度从「Demo 惊艳」切换至「OEE / MTBF / 单任务成本」工程耐力赛。物理世界的「不确定」需冗余 + 安全缓冲 + 人工兜底支付「可靠性税」——与 coding agent 的 harness 信任边界同源命题。

## 5. Dyna-2 世界-动作模型（WAM）：13 分钟适配新任务，成功率 80%→90%

- **事件**：前 DeepMind 科学家创立的 DynaRobotics 发布 Dyna-2，基于 100 万小时人类视频预训练，采用 World-Action Model（WAM）架构——联合预测下一帧视频与下一电机指令，而非传统 VLA 直接输出动作。仅 13 分钟真机遥操示范即可适配新任务，高精度制造任务成功率从 Dyna-1 的 20% 升至 80%-90%。
- **为何关注**：VLA → WAM 的范式迁移，核心在于让模型理解「动了以后世界会怎样」。这与 coding agent 的「执行前预测副作用」信任机制同理。π / GR00T / Gemini Robotics 仍走 VLA，WAM 是值得追踪的差异化路线。

## 联邦视角的收敛信号

| 维度 | AI Coding | 具身智能 | 同源命题 |
|------|-----------|----------|----------|
| 当前阶段 | 治理博弈期（标准化 + 成本护栏） | 可靠性税（进厂 + 安全认证） | 从「能力」转向「系统工程」 |
| 信任边界 | Harness 层 / Skill 可审计封装 | L2/L3 力控碰撞限值 + 紧急停止 | harness = 信任边界 |
| 成本范式 | 每任务成本 > 跑分 | 单任务成本 + OEE | 单位价值 > 峰值性能 |

> 与 ADR-238「桥接层分散注册、核心→菜单反向边砍至 4」的演进逻辑一致：把不可控的耦合收敛到可审计的边界层，才是规模化落地的真正护城河。
