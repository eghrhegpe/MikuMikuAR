## 1. Claude Opus 5 发布：编程基准翻倍、成本减半
**事件**：Anthropic 于 7 月 27 日发布旗舰模型 Claude Opus 5，主攻编程与知识型工作。Frontier-Bench v0.1 性能达 Opus 4.8 两倍以上；CursorBench 3.2 峰值分与 Fable 5 仅差 0.5%，而单任务成本仅其一半。定价每百万输入 $5 / 输出 $25，已成 Claude Max 默认模型。
**值得关注**：在「能力不降、成本砍半」的价位下，Opus 5 重新定义了高端 coding 模型的性价比基线，对 Cursor / Codex / Claude Code 等工具的实际落地成本结构有直接影响。

## 2. Claude 分享链接被谷歌公开收录 — AI 隐私治理再敲警钟
**事件**：7 月 27 日，大量 Claude 对话分享链接因 `noindex` 标签疑似失效被谷歌索引，涉及法律策略、企业技术故障、私人聊天等敏感内容。谷歌已移除大部分结果，Anthropic 尚未公开回应。
**值得关注**：coding agent 的会话天然含密钥、架构、业务故障等机密；分享/缓存/索引链路的默认安全假设不可信。这是继 ADI（Agent Data Injection）之后，又一个提醒：agent 的「可信边界」必须包含其输出产物本身。

## 3. MCP 2026-07-28 终版规范今日发布 — 无状态核心 + Apps/Tasks + OAuth
**事件**：Model Context Protocol 最大修订今日（7/28）正式定稿：移除 `initialize` 握手与 `Mcp-Session-Id`，协议走向无状态核心（每请求携带 `_meta`）；新增 Extensions 框架、Tasks、MCP Apps（沙箱 iframe 渲染的交互式 HTML）；授权对齐 OAuth 2.1。生态已超 10,000 个已发布 server，SDK 同步 beta。
**值得关注**：契约测试与工具链若触达 MCP，需在 12 个月弃用窗口内完成迁移——我们的前端 Backend 适配器双实现（ADR-176）与 Web Loader 路径统一（ADR-177）应评估是否引入 MCP 作为统一工具接入层��

## 4. Jim Fan × 李飞飞团队 RoboTTT：机器人「上下文 Scaling」实现 5 分钟肌肉记忆
**事件**：7 月 27 日，英伟达 Jim Fan 与斯坦福李飞飞团队发布 RoboTTT，将视觉运动上下文扩展到 **8K 时间步（≈5 分钟）**，比现有 SOTA 策略高 3 个数量级且不增加推理延迟；用 TTT（Test-Time Training）层把历史写入快速权重。8K 上下文比 1K 预训练同模型提升 **+62%**。支持人类视频一次性模仿与实时自我修正。
**值得关注**：上下文长度成为机器人基础模型的**新 scaling 轴**——与 coding agent「长上下文退化」恰成镜像对照。具身侧的「上下文工程」与 coding 侧的「上下文工程」正在汇流为同一命题：如何给智能体供给正确且足够长的记忆。
