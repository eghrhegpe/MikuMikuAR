## ① DeepSeek 开源首个 Agent 运行框架 Harness（DSH），补齐 Vibe Coding 执行层

**事件内容**
8 月 13 日晚，DeepSeek 发布并开源 **DeepSeek Harness（DSH）** 开发者预览版——自研 Agent 运行框架，可将大模型接入文件系统、终端、网页、代码工具及其他 Agent，负责上下文管理、工具调用与任务执行。架构采用"一切皆插件"：
- 支持 Web UI / TUI / Headless 三种模式
- 原生支持多 Agent 协作
- 可让模型直接进入代码库完成"查找文件 → 修改代码 → 跑测试 → 据报错继续修正"连续任务

此次发布紧随 **DeepSeek-V4-Pro** 正式版上线（重点强化编程与 Agent 能力），标志 DeepSeek 从"基础模型 + API"供应商，进入 Claude Code / Codex 所在的 **AI 编程执行层**竞争。

**值得关注的原因**
Harness 的意义不只是多了一个编程工具，而是 DeepSeek 开始掌握"模型 ↔ 真实工作环境"之间的**执行层**。这与联邦近期判断高度同频——coding 价值正从单体模型跑分迁移到 harness/编排层。DSH 的"插件化 + 多 Agent 协作"思路，对评估 action-defs 桥接解耦（ADR-238）的通用性有参照价值：执行层标准化正在成为大模型厂的必争之地。

## ② AWS 开源 Kiro Crew：持久化多 Agent 工作区，Agent 7×24 跨会话运行

**事件内容**
8 月 4 日 AWS 开源 **Kiro Crew**（前身是 Amazon 内部项目 MeshClaw，6 个月内 3.9 万+ Amazon 工程师使用、500+ 贡献者）。它不是一个编码助手，而是一个**持久化 Agent 工作区**：
- Agent 跨会话保留记忆、经验、技能
- 支持 cron 定时任务（晨报、PR 监控、flaky test 检测）
- Webhook 触发（Slack / GitHub 事件 / CI 失败自动拉起 Agent）
- 多 Agent 隔离上下文协调
- 安全：OS 级沙箱、默认拒绝命令、签名审计日志

定位差异：Kiro IDE 是交互式编码 editor；Kiro Crew 是"你不在时仍在工作的编码队友"。

**值得关注的原因**
"cron + webhook 抽象"是"AI 在你睡觉时工作"的正确建模。内部 3.9 万工程师采用是强信号——这不是 demo，是 Amazon 自己规模化使用的生产工具。对联邦的自动化任务系统（每日 AI 日报推送即同类范式）有直接借鉴：持久化 Agent + 事件触发 + 审计日志，正是工程纪律内建的方向。

## ③ Dyna Robotics 发布 DYNA-2 世界动作模型：纯人类视频训练，首现"人到机器人"Scaling Law

**事件内容**
8 月 10 日 Dyna Robotics 发布 **DYNA-2 World-Action Model（WAM）**，首个完全基于 **100 万+ 小时第一人称人类视频**（约 170 年连续清醒经验）预训练的机器人基础模型：
- 架构：双目标（next-frame 预测 + next-action 预测）的世界建模
- 跨本体迁移：无需预训练见任何机器人帧，人类运动直觉直接迁移到机械臂 / 人形 / 灵巧手
- 缩放律：性能随人类视频数据量平滑、可预测提升，无平台期
- 效率：13 分钟机器人数据即可让五指手学会拧瓶盖；制造任务成功率从 20% 升至 80–90%（仅靠预训练规模，后训练数据不变）
- 实测：客户部署通过率 87%（上代 VLA Dyna-1 为 46%）；真实评估任务完成数 1.55× 于 Dyna-1

**值得关注的原因**
具身智能数据瓶颈（人工遥操作稀缺、昂贵、不可扩展）被"视频替代动作数据"的新缩放轴绕过。这是继世界模型 + VLA 组合范式后，又一关键范式突破：**用无处不在的视频数据预测性缩放物理 AI**。对联邦"Babylon.js 场景仿真 / 数据合成"方向有直接启示——仿真/视频数据正成为具身训练的可扩展供给，印证"数据基建 > 动作表演"。

## ④ 小米开源 Xiaomi-Robotics-1（XR-1）：10 万小时真实数据 VLA 基座，完整开放训练部署链路

**事件内容**
8 月 5 日小米发布 **Xiaomi-Robotics-1（XR-1）** 完整开源套件——视觉-语言-动作（VLA）基础模型，基于 **10 万+ 小时真实世界操作轨迹**（UMI 装置采集，覆盖家庭/商/工/户外 1700+ 情境），现已向研究者免费开放：
- 开源内容：模型权重 + 代码 + 真机后训练 + 部署 + Benchmark 评测程序
- 两阶段：大规模预训练 + 跨本体后训练（1 万+ 小时跨机器人数据，含 7200+ 小时自有真机家庭数据）
- 小样本：每任务 <10 小时示范成功率 75%（基线 π0.5 为 40%）；<40 小时升至 85%
- 模拟基准：RoboCasa365 57.4%、RoboDojo 20.07 等均领先先前最佳

**值得关注的原因**
国产具身基座首次"权重 + 代码 + 后训练 + 部署 + 评测"全链路开源，竞争焦点从单一机器人产品转向**数据规模 / 模型泛化 / 开发工具链**。与阿里 Qwen-Robot"手/脚/脑"模块化思路互补——XR-1 证明大规模预训练可降低新技能学习的数据成本。对联邦评估国产具身生态成熟度、未来接入外部策略接口有风向标意义。
