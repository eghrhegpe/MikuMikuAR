## 关键洞察（从锐评中提取）

### 1. 分流方向正确，但 ROI 被夸大
- ✅ **真实收益**: docs-only 场景占 31% push，节省 ~30s/check
- ❌ **夸大收益**: 168h/年 → 实际约 **5-7h/年**（按正确公式重算）
- **结论**: 分流有价值，但不要吹牛

### 2. 三层框架简化为两态
- 锐评指出：工程实现只有"阻断/非阻断"两态
- **建议**: P1（建议）和 P2（参考）合并为"非阻断层"
- **理由**: 减少认知负担，避免"建议但不执行"的灰色地带

### 3. 最大遗漏：check-env-parity
- data-report 发现：75% CI 失败是 env-parity 漂移
- **但主 ADR 忽略了这条建议**
- **处置**: 标记为 Phase 1 待办（未实施）

### 4. 缓存漏洞（锐评额外发现）
- pre-push 中 lint/tsc/vitest 的缓存键**只 hash 文件路径，不含内容**
- **风险**: 文件内容改动但不增删文件时，缓存命中 → 错误被跳过
- **建议**: 改为路径 + 内容哈希
