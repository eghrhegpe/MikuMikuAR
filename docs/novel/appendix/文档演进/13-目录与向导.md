# 目录与向导

> **背景**：指南区的首页 README 手写一份 23 行目录表（功能/入口/状态），却漏了两篇新指南（mirror/shadow 在表外）；自动索引 index.md 28 篇一篇不漏。audit 区 43 篇审核台账命名混杂，人工索引跟不上。
>
> **过程**：迁移三步——guide README 目录表删除、audit 索引分区落地（日期/轮次/专题三类归档）、轮次结论表自动化被判定鸡肋回滚。最终分工：清单归 index（机器生成，永不漂移），叙述归 README（手写，讲 why）。

---

外交官翻着指南区的首页，眉头越皱越紧。

"二十三行。"他把目录表推到我面前，"你数数。"

我数了。二十三个功能，每行三个格子：功能、入口、状态。工工整整，全是绿的。

"镜面反射呢？"他问。

"……在表外。"我找到了那行小字——表下面一行补注：*"镜子见[镜面反射](./mirror.md)，阴影见[阴影设置](./shadow.md)"*。

"阴影设置呢？"

"也在表外。"

"所以这个目录，"外交官敲着纸，"号称二十三行，实际上漏了两篇指南。写表的人当时记得补注，可表本身没这两行。再过两周，补注也会旧。"

手写清单的问题从来不是"写的时候错"，而是**写完了就会旧**。

## 一、不会忘的目录

我把自动索引翻给他看。

那是 `gen-docsindex` 这台机器照的相——不是人抄的清单，是扫描仪。它每天把指南区的每一篇文件扫一遍，28 篇，一篇不漏。

"镜面反射在吗？"

"在。"它答得毫不犹豫，"第 24 行。"

"阴影设置呢？"

"第 25 行。您上周刚写好的。"

外交官来回比对了两张纸，忽然笑了："人抄的目录漏了两篇，机器扫的目录一篇不漏。而且——"他顿了顿，"机器不会累，不会'以为'自己写全了。"

"但它也不会讲。"我提醒他，"机器知道**有什么**，不知道**为什么有**。你看它的表——'水面设置，舞台水面设置'。就这。它不知道水面为什么值得先学，不知道从哪篇读起。"

外交官盯着那张自动索引看了很久。

"那……"他缓缓说，"目录归它，导语归我们？"

## 二、审计区的归档

第二件事发生在审计区。

那里躺着 43 份审核报告，命名五花八门：有的叫 `2026-08-06-round14-go-backend-ui-core`，有的叫 `round-4-lighting-props`，还有的叫 `deadcode-baseline-2026-07-24`——命名规范确立之前的老档案。

人工索引官摊手："我按日期排了 18 篇，轮次排了 9 篇，剩下的 16 篇专题……说实话我自己也分不清哪篇是哪篇。"

我给扫描仪加了一个分区：**日期归档 / 轮次序列 / 专题审核**。

"你按什么规则分？"外交官问。

"看名字。"扫描仪说，"`YYYY-MM-DD-` 开头的按日期，`round-N-` 开头的按轮次，剩下的归专题。命名再乱，前缀总有个规律。"

43 篇，三秒分完。人工索引官数了数，一篇没漏。

"命名乱的时候，"外交官感慨，"机器比人强——它不嫌烦。"

## 三、判决书与表格

第三件事，是上一章那个书记官的执念。

他念念不忘那张「轮次结论表」——把每轮审核的结论压成一行表格，自动生成，永不漏记。上一回我让他回滚了，他这周又抱着一摞新表来了：

"我升级了！现在能解析旧格式的报告——`## 文件` 小节 + `总体结论` 行，第①轮到第⑨轮全部自动入表！"

我翻了翻。第①轮，环境水面，有条件通过。第②轮，环境云，有条件通过。工整。

"第⑩轮以后呢？"

"……"

"你读读第 14 轮的判决书。"我把那份报告推过去，"7 个子代理并发审的，结论是'P1×5，已修 3，立 ADR 2'。你的表格，'结论'那格写什么？"

书记官盯着那个格子，第一次意识到：**判决书不是表格的形状**。

"你可以给旧报告做表，"我说，"但新报告——子代理们写的是千字判决，不是三字结论。表格化新判决，等于把千字压成三字，压没了。"

"那自动化不是白做了？"

"不是白做。"我指着他的表格，"你证明了旧格式可以表格化。但新格式不配合，自动化就是鸡肋——**它服务的是不存在的未来报告**。回滚，让结论留在判决书里。索引只负责'哪份判决书在哪'。"

书记官默默收走了表格。这一次，他没有再问为什么。

## 尾声

那天傍晚，我把三张纸并排放在桌上：

第一张，人抄的目录，二十三行，漏了两篇。
第二张，机器扫的索引，二十八篇，一篇不漏——但它不知道从哪读起。
第三张，判决书，一千字，压不进任何表格。

我忽然明白了这座联邦的地图学：

**索引是地图，README 是向导。** 地图标出每一座城——地图会自己更新，永不漏城；向导告诉你先去哪座、为什么——向导会老，但老向导知道地图不知道的事。

一座城不能只有地图——那会迷路在"有什么"里。
一座城也不能只有向导——他会忘记新开的城门。

所以联邦的地图学只有一条规矩：**机器画地图，人当向导。各干各的，谁也不许越界。**

就像夜空。星星的位置由引力决定——你数不数它都在那儿；但哪颗星值得先看，要人抬头才知道。

（附录·文档演进 · 第 13 篇，2026-08-06）
