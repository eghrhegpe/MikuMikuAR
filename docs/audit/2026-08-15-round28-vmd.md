## 测试质量评价

**结构与运行**：10 个 describe / 49 用例，`@vitest-environment node` 恰当（纯 Node 模块、无 DOM 依赖）。实测 49/49 全绿（167ms），grep 确认无 `it.skip`/`it.only`/`describe.skip`/`todo`。

**有效性（真实绑定生产代码）**：全部断言直接 `import` 生产源码（vmd-writer 9 导出、vpd-parser 4 导出），零 mock、零镜像复刻——写出的 buffer 用 `DataView` 按偏移回读帧号/位置/权重/插值字节，是真实二进制结构断言：帧尺寸（111/23）、总尺寸公式（54+3·111+4+2·23+16）、签名（20 字节 'Vocaloid Motion Data'）、计数偏移（50/54+3·111）、trailer 四零、空输入最小结构（74 字节）。任何偏移漂移/字节序反转/计数错位都会使测试失败。

**边界覆盖（优秀）**：编码四态（UTF-8 / UTF-16LE BOM / UTF-16BE BOM / Shift-JIS 探测）+ BOM 剥离 + 空 buffer 返回 '' + 超限 1MB throw；双字节截断字符边界（14/15 字节精确断言）；sanitize 空名 → `_`；`canEncodeName('😀')` false；插值钳制与预设；排序且不改入参；注释/分号/逗号/花括号/空文本格式变体；纯 morph 拒绝。安全 CVE 修复点（sanitizeName、MAX_VPD_SIZE、XML 实体剥离、try/catch 降级、长度+isFinite 校验）在源码全部在位，本测试未重复覆盖（由 `vpd-parser-security.test.ts` 29 项专项覆盖，分工合理）。

**弱断言/盲区**：① L291 `nameBytes.some(b => b !== 0)` 只验"非全零"；② L174-184 Shift-JIS 用例只验含 'Vocaloid' 且无 U+FFFD，未断言解码出的骨骼名；③ L210-212 只验 position x/y，未验 z 与 rotation；④ 模型名字段（offset 30-49）无断言；⑤ morph 权重越界（writer 不钳制、0..1 外值直写）无测试；⑥ 同名重复帧行为无测试。均为 🟢 P4 级，不阻断。
