## ✅ 亮点

- **MAX_VISIBLE 同步裁剪，规避异步死循环**（`toast.ts:204-212`）: `while (_activeToasts.length >= MAX_VISIBLE_TOASTS)` 直接同步 `removeToast` 而非 `fadeAndRemoveToast`，注释点明「避免 fadeAndRemoveToast 异步导致死循环」——这是真实踩坑后的正确决策记录；同时 eviction 走 `removeToast` 完整清理定时器与 DOM，无泄漏。
- **document 守卫降级**（`toast.ts:199-203`）: `typeof document === 'undefined'` 早退 + `console.warn`，覆盖 round-12 P2#9 headless 场景，不向调用方抛错冒泡；测试 T1 显式验证「不抛错 + 有告警」。
- **定时器双向清理 + 淡出可中断、幂等**（`toast.ts:40-57, 75-94`）: `fadeAndRemoveToast` 前置 `clearTimeout(entry.timer)` + `clearTimeout(entry.fadeTimer)` 再重排，close 中途二次点击/与自动淡出竞态时均安全；`removeToast` 对已移除 id 幂等返回，内层 `removeToast(id)` 即使重复触发也是 no-op——状态机防御性完备。
- **aria-live 状态机**（`toast.ts:60-73` + :219-222）: 容器 `role="status"`/`aria-live="polite"`/`aria-atomic="true"` 为基底，error 变体切 `role="alert"`/`assertive`，最后一个 error 移除后 `_syncToastAriaLive` 回退 polite——与 ADR-153 Phase 1.2/决策 6、7 完全对齐。
- **XSS 防护与 i18n 纪律**（`toast.ts:121,128,140,162,177`）: 用户可控文本一律 `textContent`（无 innerHTML），复制文案 `title\n detail` 拼接、按钮文案全走 `t()`；5 语种 key 已逐一核实齐全。
- **测试卫生**（`toast.test.ts:25-35`）: `vi.useFakeTimers()`/`vi.useRealTimers()` 成对、`vi.unstubAllGlobals()` + `vi.restoreAllMocks()` + `document.body.innerHTML=''` 三件套齐全，符合 frontend/AGENTS.md 测试铁律；mock `./i18n/t` 为 identity 工厂（`t: (key) => key`），只引用自身形参、无 hoist 期 TDZ 风险，与真实 `t()` 缺失 key 回退键名语义一致。

## 测试质量评价

**总体**: 良好（12/12 通过，断言有效、定时器与全局 stub 卫生合规），但有 1 项 P2 隔离缺陷与若干覆盖缺口。

- **断言有效性**: ✅ 全部用例断言真实 DOM/调用副作用（`container().textContent`、`toastCount()`、`onClick` 调用次数、`writeText` 入参），无 mock 自证；`./i18n/t` 的 identity mock 使翻译键原文可断言（`toast.copy`→`toast.copied` 复原链、`motion.clipboardUnavailable` 降级文案），设计合理。
- **document 守卫（P2#9）**: ✅ T1 同时断言「不抛错」+「warn 被调」，且 stub/restore 通过 `vi.stubGlobal`/`vi.unstubAllGlobals` 成对，未污染后续用例（frontend/AGENTS.md 铁律合规——stub 的是 `document`/`navigator` 而非 `window`，无全局污染风险）。
- **fake timers**: ✅ `beforeEach`/`afterEach` 成对切换、`advanceTimersByTime(Async)` 对异步 clipboard 路径（`await` 后断言 + 复原）处理正确，T9/T10 的三段推进（触发→淡出→移除）与源码 50/150/300ms 时序逐段对应，注释同步。
- **跳过测试**: 无。
- **覆盖缺口**: ① aria 回退路径（P3-4）；② 裁剪后定时器不复活（P3-4）；③ T2 未断言默认 variant='error' 时容器 role=alert（只查 aria-live 存在）；④ 未测 `showInfoToast` 默认 3000ms 时长参数透传（生产 40+ 调用点，未直接断言但 T10 已覆盖 duration 透传机制）。
- **隔离缺陷（P2-2）**: 模块级 `_activeToasts` 跨用例残留，MAX_VISIBLE 用例语义被污染、靠幂等性偶然通过；`--sequence.shuffle` 复跑 12/12 通过（见执行摘要），佐证「被幂等清理掩盖、暂不触发失败」。
- **测试契约锁定风险（P2-1 关联）**: close 测试用 `span[aria-label]` 选择器把「非按钮关闭控件」锁进契约，修复 P2-1 时须同步更新该选择器。
