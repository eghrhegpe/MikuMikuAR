## 亮点

- **文件头「覆盖策略 + 未覆盖声明」诚实完备**（scene.test.ts:3-27）：明确列出 MPR 构建期常量分支、真实 WebGL、headless NullEngine、`initMotionBroadcast` 二次动态 import 的 vitest mock 怪癖、observe 回调体不触发等**无法触达的路径及原因**，并给出规避设计（`__MMD_ENABLE_MPR__` 显式 stub、Engine 最小假对象）。这是「测试能力边界透明化」的最佳实践，后续维护者不会误以为漏测。
- **断言与守卫组合针对性强**：涟漪回调单用例串联 7 种跳过条件（非 POINTERDOWN / 水面关闭 / hit / 无 ray / direction.y≥0 / 相机缺失 / 相机低于水面 / t≤0 / 超地面范围）与 1 条命中路径（scene.test.ts:968-1069）；拖拽回调串联 未启用/非 UP/拖拽中/位移过大 4 种守卫 + 1 命中（1071-1099）。对「守卫分支」而非「happy path」的覆盖密度是模块测试标杆。
- **模块级状态隔离**：每用例 `vi.resetModules()` + 动态 import 获取全新模块实例（scene.test.ts:26,651-675），`_sceneInitialized/_sceneDisposed/_initPromise` 等模块级状态逐用例重置，且 `shared.sceneActions` 显式清场（671-673）——杜绝用例间状态串扰。
- **`onRemoveModel` 异步清理的 `scene.isDisposed` 守卫被真实断言**（scene.test.ts:1238-1257）：两条用例分别验证 dispose 后跳过 / 未 dispose 执行 `teardownWasmLayersBlender` + `disposeVirtualSkirtForModel`，精确对应 scene.ts:647-666 的 fire-and-forget 微任务时序。
- **源码 dispose 链路完整且带抛错隔离**：`tryDisposeSubsystem` 逐个包装（scene.ts:277-283），scene/engine.dispose 单独 try/catch（340-349）——round-14 P1 的「任一子系统抛错不阻断 WebGL 最终释放」修复在位；`_sceneDisposeObserverHandle` 经 `safeDispose` 释放（300-302）。
- **initScene 并发守卫 `_initPromise`**（scene.ts:409-427）与 HMR 重入 `_reinitSceneForHMR` 清理链（disposeScene → stop 各运动子系统 → disposeAudioBus/disposeAudio → unsubscribeAll → cancelEnvPersistTimer → stopTimeOfDay，489-512）在测试中被真实验证（809-821 六条断言）。
- **共享 helper 去重**（scene.test.ts:643-649）：round6 audit 已把两 describe 内联的逐字相同 `getOnRemove` 合并为模块级一份。

## 测试质量评价

- **断言有效性：高**。生命周期（initScene 装配序、dispose 级联、HMR 重入清理）、回调（onModelLoaded/onRemoveModel/指针涟漪/拖拽/运动子系统收集器）、守卫（isHeadless 恒 false、重复 dispose 幂等、modelManager 未初始化、scene.isDisposed）均被真实行为断言（toHaveBeenCalledWith 带参断言占比高，如 `solveIkNative({}, { bones: [] }, 2, true)`、`setTriggerAutoSave(shared.triggerAutoSaveImpl)`）。
- **mock 合理性：总体合理，两处例外**。`vi.hoisted` shared 单例 + getter 暴露可变配置（uiState/envState/mmdRuntime/focusedModelId）驱动分支，属可控的「黑盒行为替身」，非掩盖实现的哑 mock；但 `../core/audio` / `motion-intent` 未 mock 真实加载（见 P3），且 `initLoader` 回调按参数位置取用（见 P2）是仅有的两处失真。
- **边界覆盖：强**。帧率 4 分支（含 fpsLimit=0/undefined/限制器关闭）、涟漪几何条件全组合、拖拽 4 守卫、IK resolver 4 分支、幂等与 HMR 重入均覆盖；未覆盖 initScene 失败路径（P3）。
- **无跳过测试**：`grep skip|only|xit` 零命中，46 个 it 全量执行（验证运行 46 passed）。
- **测试文档**：文件头未覆盖声明 + 行 785-786「[实测证实] code_review 静态推理误判」的实测纠偏记录，表明测试与实现经过实证对齐而非纸面对照。
