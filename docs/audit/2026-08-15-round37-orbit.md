## 亮点

- **零 import 纯函数叶设计**：`orbit.ts` 无任何 import，stateless 纯函数，无资源分配/Observer/状态 → 资源释放与并发安全两项自动豁免，职责单一（转换 + 钳制），`frontend/src/core/orbit.ts:1-69`。
- **异常路径全封闭（模块级不变量"绝不 NaN"）**：`orbitToCartesian` 对 azimuth/elevation/distance 三参数逐一有限性 + 值域钳制（`orbit.ts:43-47`）；`cartesianToOrbit` 对 `len===0` 与非有限 len 返回原点轨道坐标（`orbit.ts:62-65`）；`normalizeOrbit` 为存储层兜底（`orbit.ts:25-30`）。三层互补，覆盖 损坏文件反序列化 / UI 越界 / 运行时脏值 三类入口。
- **魔法数值具名化**：距离下限抽为 `MIN_ORBIT_DISTANCE = 0.001` 常量并带注释说明动机（`orbit.ts:14-15`），测试直接引用常量而非硬编码（`orbit.test.ts:112,220-223`）。
- **测试断言真实有效（非形式主义）**：
  - 已知坐标用例**双重验证**——既对照解析公式（`orbit.test.ts:23-25`）又核对数值基线 `[6.12372, 5, 6.12372]`（`orbit.test.ts:27-28`），可发现公式与约定同时写错的场景；
  - `distance=0` 用例**数值化验证长度 ≈ MIN_ORBIT_DISTANCE**（`orbit.test.ts:110-112`），不是只断言"有限"；
  - 大向量用例选值 1e150 贴近 double 平方溢出阈值 1.8e154，真正覆盖"平方不溢出"路径（`orbit.test.ts:205-211`）；
  - gimbal lock 极点用例正确表述取舍：断言有限 + 仰角/距离一致，注释明示"方位角丢失属数学固有"（`orbit.test.ts:189-203`）；
  - **故意行为被测试固化**：azimuth 不做角度归约（720 原样保留）由用例钉死（`orbit.test.ts:242-245`），防止未来有人"顺手"加 mod 360 改变行为。
- **测试组织纪律好**：按 ADR §6 验证标准分 describe（#1 已知坐标 / #2 模式往返 / 边界保护 / normalizeOrbit），关键取舍（原点退化、旧硬编码 0.1）均在注释中说明（`orbit.test.ts:54-55,168`）；`@vitest-environment node` 正确（纯数学无 DOM）。

## 测试质量评价

**总体：优**。25 用例 / 0 跳过 / 0 失败（`npm run test -- src/__tests__/orbit.test.ts`，59ms）。

- **断言有效性（真实验证）**：✅ 已知坐标双向核对（公式 + 数值基线）；✅ 距离钳制用数值长度验证（非"断言有限"形式主义）；✅ 往返一致性双向覆盖（orbit→cartesian→orbit 与 cartesian→orbit→cartesian 各 3/7 用例）；✅ 大向量选值贴近溢出阈值。
- **边界覆盖（强项）**：NaN/Infinity 全参数组合、distance=0/负值、elevation ±100 越界收敛、±90 精确边界不误收窄、原点退化特例、gimbal lock 极点、sub-MIN 极小向量、极大向量——覆盖密度明显超出 ADR §6 最低要求（§6 仅要求 #1/#2 两条，测试扩展出 23 条边界用例）。
- **短板（3 处，均为 P3/P4）**：
  1. **sub-MIN 波段往返缺口**（0 < len < 0.001）：有单向用例无往返用例，恰好绕开已知的非恒等行为（风险表 P3 行）；
  2. **"极大坐标"用例名不副实**：1e10 量级断言必过，未验证精度保持（P4）；
  3. **无角度归约/环绕类用例**：azimuth 大角度（720/-360）仅断言原样保留，未覆盖"若未来引入归约，往返方位角模 360 等价性"——属当前刻意不归约策略下的合理省略，但文档应同步。
- **无跳过/无 flaky 迹象**：纯函数、无 mock、无时间依赖，node 环境，运行稳定。
