# 程序化动作

## 它能做什么

**不用导入 VMD** 也能让角色动起来：程序化生成「待机」（呼吸、小幅摆动）或「自动跳舞」动作，还能随音乐**节拍联动**、叠加视线/头部追踪，让静止的模型自然生动。

## 打开方式

1. 打开「**动作**」面板
2. 进入「**程序化动作**」分区（路由 `motion:proc-library`）

## 操作步骤

### 1. 选择模式

| 模式 | 效果 |
|------|------|
| 关闭 | 不生成程序化动作 |
| 待机（Idle） | 呼吸起伏 + 细微摆动，适合角色站立展示 |
| 自动跳舞（Auto Dance） | 程序化生成舞蹈动作，配合音乐更佳 |

### 2. 调整幅度与速度

- 「**强度**」：动作幅度大小（越大动得越夸张）。
- 「**速度**」：动作节奏快慢。

### 3. 骨骼分类微动

- 可分类开关哪些部位参与微动（如仅头部、仅上身），实现更克制的待机效果。

### 4. 节拍联动（配合音频）

- 开启 **BPM 节拍量化** 后，动作会对齐当前音乐节拍——先在动作面板加载音乐（见 [动作与播放](./motion-playback.md)）。

### 5. 视线 / 头部追踪

- 开启后角色视线/头部会追随（配合感知层），静止时也有「活人感」。

## 常见问题

**Q：开了自动跳舞但动作很随意、不踩点？**
A：需先加载音乐并开启 **BPM 节拍量化**；无音频时舞蹈是自由节奏。

**Q：程序化动作和导入的 VMD 冲突吗？**
A：VMD 播放优先；程序化动作主要用于无 VMD 或待机场景，两者不会同时全身驱动。
