# 场景保存与恢复

## 它能做什么

你的舞台**自动保存**——摆好的模型、动作、环境、相机都会在改动后自动存盘，下次打开自动恢复上次的样子。误操作可**撤销/重做**，还能用**预设场景**一键切换到内置的成套环境布置。

## 打开方式

- 保存/恢复是**自动的**，无需手动操作。
- 预设场景：「**场景**」弹窗 → 「预设场景」（路由 `scene:presets`）。

## 操作步骤

### 1. 自动保存（无感）

- 摆放模型、调参数、移动相机后，系统会在稍作停顿时**自动存盘**（防抖，不会频繁写）。
- 无需点「保存」按钮——正常退出后下次启动会**自动恢复**上次场景。

### 2. 撤销 / 重做

- 破坏性或大改动后可**撤销**回上一步（也支持重做）。
- 撤销基于快照栈，栈满时最旧的快照会被丢弃。

### 3. 预设场景

- 「预设场景」里选一套内置布置（环境 + 光照等成套参数），一键套用，快速起稿。

## 常见问题

**Q：改了东西没手动保存，退出后丢了吗？**
A：正常退出会自动存盘并在下次恢复。但**强制杀进程/崩溃**时，最后一次防抖窗口内的改动可能来不及落盘——重要改动后稍等几秒再退出更稳妥。

**Q：套用了预设场景，之前的布置没了？**
A：可用**撤销**回到套用前的状态。

**Q：怎么彻底重来？**
A：清空场景或加载新场景即可；单个改动用撤销更精细。
