# 道具

## 它能做什么

在舞台中**加载道具模型**（麦克风、椅子、手持物等独立 PMX），并调整其位置、旋转、缩放——道具独立于角色，可单独变换或跟随绑定。

## 打开方式

1. 打开「**场景**」弹窗
2. 进入「道具」（路由 `scene:props`）

## 操作步骤

### 1. 加载道具

- 道具分区 →「添加道具」→ 从模型库选择 PMX 道具文件
- 加载后道具出现在舞台中心（可拖拽到目标位置）

### 2. 变换道具

| 操作 | 方式 |
|------|------|
| 移动 | 选中道具 → 拖拽（或道具分区 → 位置偏移） |
| 旋转 | 道具分区 → 旋转 XYZ 角度 |
| 缩放 | 道具分区 → 缩放倍率 |

### 3. 道具与角色联动（进阶）

- 部分道具支持绑定到角色骨骼（如「手持」）——绑定后道具跟随角色动作，需在动作模块配置

### 4. 移除道具

- 选中道具 →「卸载」即从舞台移除（不删除文件）

## 常见问题

**Q：道具加载后穿模/悬浮？**
A：道具是独立网格，需手动调整位置到目标点；若绑定骨骼，检查绑定骨是否正确。

**Q：道具列表里没有想要的模型？**
A：先到 [模型导入](./import-model.md) 把道具 PMX 加入模型库，再回到道具分区加载。
