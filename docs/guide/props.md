# 道具

## 它能做什么

在舞台中**加载配件模型**（麦克风、椅子、手持物等独立 PMX），并调整其位置、旋转、缩放。道具不再有独立入口——它就是一个普通模型：从**模型库**加载到舞台，再按需**绑定到角色骨骼**跟随动作。

## 打开方式

1. 点击主界面底部「**模型库**」按钮，打开模型库弹窗
2. 选择配件 PMX 文件 → 「加载模型」

> 说明：早期版本的「场景 → 道具」独立面板已取消（ADR-215）。所有配件模型一律作为普通模型加载，再通过骨骼附属建立与角色的关系。

## 操作步骤

### 1. 加载配件

- 模型库 → 选择 PMX 配件文件 → 加载
- 加载后出现在舞台中心，可拖拽到目标位置（见 [模型导入](./import-model.md)）

### 2. 变换配件

| 操作 | 方式 |
|------|------|
| 移动 | 选中配件 → 拖拽（或模型详情 → 变换卡片的位置偏移） |
| 旋转 / 缩放 | 模型详情 → 变换卡片 |

### 3. 绑定到角色骨骼（进阶）

- 选中角色 → 模型详情 → 将配件**附属**到指定骨骼（如「手持」）
- 绑定后配件跟随角色动作；想分开时解除附属即可（配件仍保留在场景中）

### 4. 移除配件

- 选中配件 → 模型详情 →「卸载此模型」即从舞台移除（不删除文件）

## 常见问题

**Q：配件加载后穿模/悬浮？**
A：配件是独立网格，需手动调整位置到目标点；若绑定骨骼，检查绑定骨是否正确。

**Q：场景菜单里找不到「道具」了？**
A：道具面板已并入模型库——配件模型和其他模型一样从模型库加载，再在模型详情里做骨骼附属。
