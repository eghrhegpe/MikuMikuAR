# 姿势工作室

## 它能做什么

拍照模式的**一站式摆姿工具**：画面构图辅助线（三分法/黄金比例/对角线）、一键切换 T-pose / A-pose 标准姿势、套用相机角度预设，并支持单张截图与**批量导出**多角度成片——适合出图、做预览图集。

## 打开方式

1. 打开**动作**弹窗
2. 进入**更多 → 姿势工作室**（路由 `motion:poseStudio`）

> 需要先加载模型；未加载时面板显示「⚠ 请先加载模型」。

## 操作步骤

### 1. 构图辅助

- **构图引导**：关 / 三分法（rule of thirds）/ 黄金比例 / 对角线，画面上叠加辅助线，辅助取景。

### 2. 姿势预设

- **T-pose / A-pose / 复位**：一键应用标准姿势（生成临时 VMD），适合绑骨检查与截图；「复位」停掉当前动作回到静止。

### 3. 相机预设与截图

- **相机角度预设**：点选即套用（如正面/侧面/俯视等，悬停看说明）
- **📷 截图**：当前角度拍一张
- **📸 批量导出**：遍历全部相机预设逐张截图（带进度条），一次拿整组出图

> 景深（DOF）等镜头参数已收口到镜头菜单（动作 → 相机），不在本面板重复。

## 常见问题

**Q：点了 T-pose 没变化？**
A：确认当前模型未播放 VMD（播放中会覆盖姿势）；可先停止播放再应用预设。

**Q：批量导出很慢？**
A：批量截图逐角度渲染，预设多时耗时较长，属正常；可先在「相机预设」里减少不需要的角度。
