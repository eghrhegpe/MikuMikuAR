# 舞台灯光

## 它能做什么

给舞台添加**聚光灯/点光源**，调整颜色、强度、照射角度，并控制阴影开关与预设灯光方案（角色特写、产品、舞台剧、舞蹈表演）。

## 打开方式

1. 打开「**场景**」弹窗
2. 进入「舞台灯光」（路由 `scene:stageLight`）

## 操作步骤

### 1. 添加灯光

- 灯光分区 →「添加灯光」→ 选择类型（聚光灯 / 点光源）
- 新灯默认指向当前选中模型或舞台中心

### 2. 调整灯光

| 参数 | 作用 |
|------|------|
| 颜色 | 灯色（点击色块选取） |
| 强度 | 明暗（太大会过曝，配合渲染 → 泛光调节） |
| 照射角度 | 聚光灯的锥角与方向 |
| 阴影开关 | 开启后模型投射阴影（性能消耗，按需开启） |

### 3. 灯光预设

- 「灯光预设」分区 → 一键套用：**角色特写 / 产品 / 舞台剧 / 舞蹈表演**
- 预设会批量设置灯光位置、颜色与强度，适合快速布光后微调

### 4. 删除灯光

- 选中灯光 →「删除」（舞台至少保留一盏灯，避免全黑）

## 常见问题

**Q：加了灯还是黑？**
A：检查「灯光预设」是否被设为全黑，或「渲染 → 光照」总开关是否开启。

**Q：阴影太硬/没有阴影？**
A：阴影质量与开关在「舞台灯光 → 阴影」分区；阴影模式（硬/软）与模糊度也在此调整。
