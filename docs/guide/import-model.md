# 模型导入

## 它能做什么

从**模型库**浏览并加载 PMX/PMD 模型到舞台，支持搜索、标签、收藏与直接拖拽文件导入。

## 打开方式

1. 点击主界面底部的「**模型库**」按钮，打开模型库弹窗
2. 模型库按目录/标签/收藏分组展示

> 也支持将 `.pmx` / `.pmd` 文件**直接拖入窗口**快速导入。

## 操作步骤

### 1. 浏览模型库

- 模型库按「最近使用」「收藏」「标签」分组，顶部有搜索框
- 首次打开若为空，先检查「设置 → 资源 → 资源根目录」是否指向模型所在文件夹

### 2. 加载模型到舞台

- 点击模型条目 → 进入模型详情 → 选择「加载到场景」
- 加载后模型出现在舞台中心，自动居中

![模型库列表](img/import-model-1.png)

### 3. 拖拽导入（快捷方式）

- 将 PMX/PMD 文件拖入窗口，自动按资源根目录归属入库并加载

## 常见问题

**Q：模型库是空的？**
A：检查「设置 → 资源」的资源根目录；模型需放在该目录下的文件夹中（支持子目录递归扫描）。

**Q：加载后模型位置不对？**
A：使用模型详情 →「变换」重置位置，或开启「设置 → 操控 → 自动居中」。
