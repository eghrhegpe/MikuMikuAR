# 布料物理

## 它能做什么

控制舞台的**全局物理环境**：调整重力强度、开关地面碰撞，让模型的裙摆、头发等软体随动作**自然摆动**而不会穿透地面。物理由 WASM Bullet 引擎驱动。

## 打开方式

1. 打开「**场景**」弹窗
2. 进入「**物理**」分区（路由 `scene:physics`）

## 操作步骤

### 1. 重力强度

- 「**重力强度**」滑块（范围 0–2，步长 0.05）：控制软体下垂的力度。
- 数值越大裙摆/头发下坠越明显；调到 0 近似失重飘浮效果。

### 2. 地面碰撞

- 「**地面碰撞**」开关：开启后布料/软体不会穿透地面，摆动到底部会被地面挡住。
- 关闭后软体可自由下垂穿过地面（做悬空、水下场景时可关）。

## 常见问题

**Q：调了参数裙摆还是不动？**
A：布料物理需要模型本身带有物理刚体/软体骨骼定义（PMX 自带）。没有物理骨骼的模型不会响应重力。

**Q：想看骨骼/线框排查物理问题？**
A：模型级调试（线框、骨骼线、骨骼关节）在**模型详情 → 故障排除**折叠组，不在这个全局物理页。

**Q：物理开销大导致卡顿？**
A：可在 [设置](./settings.md) → 画面里关闭默认物理或降低画质档位。
