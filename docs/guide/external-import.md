# 外部动作导入

## 它能做什么

把**非 MMD 格式的动作**（如 Mixamo 的 FBX、VRM 模型动画）重定向到当前角色上播放：通过骨骼映射把外部骨架动作「翻译」成本模型能理解的动作，扩展现成动作库之外的动作来源。

## 打开方式

1. 打开**动作**弹窗
2. 进入**更多 → 外部动作导入**（路由 `motion:retarget`，需先加载模型）

## 操作步骤

### 1. 选择来源类型

- **Mixamo**：导入 Mixamo 导出的动作（FBX），自动映射常见骨骼
- **VRM**：导入 VRM 动画，按 VRM 骨骼规范映射
- **自定义映射**：手动指定外部骨骼 → 模型骨骼的对应关系，覆盖特殊骨架

### 2. 选择动作文件并确认

- 选择外部动作文件后，按提示确认/调整映射；完成后动作会加载到当前模型（后续播放方式同 VMD，见[动作与播放](./motion-playback.md)）。

### 3. 效果不佳时

- 重定向依赖骨骼命名与结构，若动作变形/错位，改用「自定义映射」手动对齐关键骨骼。

## 常见问题

**Q：导入后模型动作很怪？**
A：多为骨骼映射不准——用「自定义映射」核对肩/肘/膝等关键骨骼；也可换来源（Mixamo 标准骨架兼容性最好）。

**Q：只能对一个模型用吗？**
A：重定向后动作就绑定在当前模型；其他模型需另行导入或使用共享动作库。
