# 地面设置

## 它能做什么

控制舞台**地面**：网格/实心样式、地面高度、半透明显示与阴影，让模型「站得稳、有影子」。

## 打开方式

1. 打开「**场景**」弹窗
2. 进入「地面」分区（路由 `scene:ground`）

## 操作步骤

### 1. 调整地面样式

| 参数 | 作用 |
|------|------|
| 网格开关 | 显示经典 MMD 网格地面（调校位置用） |
| 地面颜色 | 实心地面颜色 |
| 透明度 | 地面半透明显示 |
| 网格尺寸 | 网格密度 |

### 2. 对齐高度

- 「地面高度」滑块：上下移动地面，让模型脚底贴合（模型详情 →「变换」也可微调模型高度）

### 3. 阴影

- 阴影属于光照配置：场景 → 舞台灯光 → 阴影开关/强度（`scene:stageLight`）

## 常见问题

**Q：模型陷进地面或悬空？**
A：先调「地面高度」，再用模型详情 →「变换」微调模型 Y 位置；开启「设置 → 自动居中」可避免加载错位。

**Q：网格地面想隐藏只留实心？**
A：关闭「网格开关」，保持「地面颜色」为实心色即可。
