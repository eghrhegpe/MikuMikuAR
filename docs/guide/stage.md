# 舞台渲染

## 它能做什么

加载并管理**舞台模型**（场景菜单 → 舞台）：从模型库装载舞台文件、同一时间挂载多个舞台、切换显示/隐藏、调整位置与材质，不需要时卸载。舞台与角色模型分开管理，互不干扰。

## 打开方式

1. 打开**场景**弹窗
2. 进入**舞台**（路由 `scene:render:stage`）

## 操作步骤

### 1. 加载舞台

- 舞台面板首行「**加载舞台**」→ 从模型库的舞台目录选择舞台/场景文件（`type=stage` 或 `type=scene`）。

### 2. 管理已加载舞台

- 已加载舞台会列在面板中，每行提供：
  - **👁 显示/隐藏**：一键切换舞台可见性
  - **✕ 卸载**：移除该舞台（可撤销，见[场景保存与恢复](./scene-save.md)）
- 点击舞台行进入其**变换面板**。

### 3. 调整舞台（变换面板）

- **拖拽操控**（折叠面板）：位置 / 旋转 / 缩放滑块，与模型变换一致
- **材质调节**：逐材质调参（同模型材质编辑）
- **重置 + 卸载**：恢复默认变换或卸载舞台

## 常见问题

**Q：找不到「加载舞台」按钮？**
A：首次打开需先在[设置](./settings.md)里配好资源根目录，且模型库中有舞台类文件（PMX 舞台/场景）。

**Q：舞台与模型位置对不上？**
A：舞台变换面板调「位置」Y 轴对齐地面，再配合[地面设置](./ground.md)的地面高度。
