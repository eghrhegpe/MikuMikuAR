# 动作与播放

## 它能做什么

给舞台上的模型**分配 VMD 动作**，控制播放/暂停/循环/速度，还能叠加**程序化动作**（待机呼吸、自动舞蹈、口型同步）与表情。

## 打开方式

1. 选中舞台上的模型 → 打开「**动作**」面板
2. 面板分「已加载动作」「动作库」「程序化动作」等分区

## 操作步骤

### 1. 加载动作

- 动作面板 →「浏览动作库」→ 选择 VMD 文件
- 或从模型详情 →「动作」→「分配动作」

### 2. 播放控制

| 控制 | 位置 |
|------|------|
| 播放 / 暂停 | 模型详情 →「动作绑定」面板的播放控制（或快捷键） |
| 循环开关 | 播放状态行的「循环」开关 |
| 播放速度 | 模型详情 →「动作」→「播放速度」滑块（0.1–2.0） |

### 3. 程序化动作（无 VMD 也能动）

- 动作面板 →「程序化动作」→ 选择「待机呼吸」/「自动舞蹈」
- 开启「口型同步」后模型嘴型随音频变化

![动作面板](img/motion-playback-1.png)

### 4. 表情（Morph）

- 模型详情 →「表情预览」→ 拖动滑块调整单个表情强度，或「重置所有表情」

## 常见问题

**Q：动作加载后模型不动？**
A：确认该动作与模型骨骼兼容；「动作绑定」面板可查看/固定全局动作。

**Q：多个模型想播放同一个动作？**
A：使用「跟随全局动作」——未固定动作的模型自动跟随场景全局 VMD。
