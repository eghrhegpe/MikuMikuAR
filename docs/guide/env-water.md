# 水面设置

## 它能做什么

在舞台地面之上添加**动态水面**：有波纹动画、实时反射效果，还能叠加涟漪（点击水面泛起波纹）与水下过渡效果。适合做水池、湖泊、演出舞台的镜面效果。

## 打开方式

1. 打开**场景**弹窗（点击主界面「场景」按钮）
2. 进入**水面**（路径：场景菜单 → 水面，路由 `scene:water`）
3. 打开「水面」开关即可出现水面

> 静态菜单结构（Schema 树 / items / 路由）见 [menu-map.md](../knowledge/menu-map.md) 对应节。

## 操作步骤

### 1. 启用水面

- 找到「水面」开关，开启后水面即出现，默认平铺在地面之上。

### 2. 调整外观

| 参数 | 作用 |
|------|------|
| 水面颜色 / 透明度 | 水色与不透明度 |
| 雾颜色 / 雾起止 | 水下/远景雾色与范围 |
| 大浪高度 / 涟漪高度 | 波纹起伏幅度（两层波叠加） |
| 波纹细节 / 波光闪烁 | 水面细节与高光闪烁 |
| 地平线淡出 | 水面与远处背景的过渡 |
| 波前菲涅尔 | 反射/折射强度分布（掠射角更亮） |
| 动画速度 | 波纹动画快慢 |
| 质量档位 | 高 / 中 / 低（低配降质保帧率） |

### 3. 涟漪效果

- 开启「涟漪」后，点击水面会在点击处泛起同心波纹；可调整涟漪数量、波纹细节与波光闪烁。

### 4. 进阶效果（可选）

- **焦散**：水底光斑投影（强度、颜色、滚动速度）
- **泡沫**：浪尖泡沫（阈值、强度、过渡、不透明度、噪声、颜色）
- **翻转**：上下翻转水面（配合倒影玩法）
- **色散**：彩虹色散效果

### 5. 水下过渡（可选）

- 开启后，相机进入水下时画面自动切换为水下色调（色调强度、染色强度）。

### 6. 保存预设

- 水面顶部预设芯片：一键切换常用水面方案；参数也可保存为环境预设复用（见环境弹窗 → 预设）。

## 常见问题

**Q：水面为什么是纯镜面没有波纹？**
A：把「涟漪高度」调大试试——两层波浪（大浪/涟漪）都调低时水面刻意保持纯净反射面（这是设计行为，不是故障）。

**Q：水面出现在不该出现的位置？**
A：水面位置跟随地面；可先检查场景菜单 → 地面 → 高度（`groundLevel`）设置。
