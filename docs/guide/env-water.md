# 水面设置

## 它能做什么

在舞台地面之上添加**动态水面**：有波纹动画、实时反射效果，还能叠加涟漪（点击水面泛起波纹）与水下过渡效果。适合做水池、湖泊、演出舞台的镜面效果。

## 打开方式

1. 打开**场景**弹窗（点击主界面「场景」按钮）
2. 进入**水面**（路径：场景菜单 → 水面，路由 `scene:water`）
3. 打开「水面」开关即可出现水面

> 静态菜单结构（Schema 树 / items / 路由）见 [menu-map.md](../knowledge/menu-map.md) 对应节。

## 操作步骤

### 1. 启用水面

- 找到「水面」开关，开启后水面即出现，默认平铺在地面之上。

### 2. 调整外观

| 参数 | 作用 |
|------|------|
| 水面颜色 / 雾颜色 | 水色与远景雾色 |
| 波浪强度 / 波高 | 波纹起伏幅度 |
| 反射模糊 | 反射清晰度（越大越朦胧） |
| 小波细节 | 开启后叠加精细小波纹（关闭时水面呈纯净镜面） |

### 3. 涟漪效果

- 开启「涟漪」后，点击水面会在点击处泛起同心波纹；可调整涟漪强度与衰减。

### 4. 水下过渡（可选）

- 开启后，相机进入水下时画面自动切换为水下色调。

### 5. 保存预设

- 水面参数可保存为环境预设，之后一键复用（见环境弹窗 → 预设）。

## 常见问题

**Q：水面为什么是纯镜面没有波纹？**
A：检查「小波细节」开关——关闭时水面刻意保持纯净反射面（这是设计行为，不是故障）。

**Q：水面出现在不该出现的位置？**
A：水面位置跟随地面；可先检查场景菜单 → 地面 → 高度（`groundLevel`）设置。
