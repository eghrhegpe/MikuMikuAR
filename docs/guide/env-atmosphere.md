# 环境氛围

## 它能做什么

对舞台做**氛围与画面微调**：加雾营造纵深、加云丰富天空，以及一组画面后处理（辉光 Bloom、暗角、锐化、环境光遮蔽 SSAO 等）提升整体质感。

## 打开方式

- 雾：**环境**弹窗 → 「雾」（`env:fog`）
- 云：**环境**弹窗 → 「云」（`env:cloud`）
- 后处理：**环境/场景**弹窗 → 「后处理」（`env:postprocess`）

> 雾与云有独立细分页（参数更全 + FAQ），本页作为氛围总览只保留要点。

## 操作步骤

### 1. 雾（要点）

- 雾模式：`exp2` / `exp`（指数雾，用密度）/ `linear`（线性雾，用起止距离）
- 切换模式后「密度」与「起止距离」自动显隐——看不到某参数是当前模式不用它
- 完整参数与 FAQ 见 [雾设置](./fog.md)

### 2. 云（要点）

- 云开关：开启后天空叠加体积云（配合[天空设置](./sky.md)共同构成天空氛围）
- 完整参数（覆盖度/间隙/侵蚀/天气强度/高度/缩放/厚度/可见度/背光/粉度）见 [云层设置](./cloud.md)

### 3. 画面后处理

| 分组 | 参数 | 作用 |
|------|------|------|
| Bloom 辉光 | 强度 / 阈值 / 核大小 / 描边 | 亮部泛光，营造梦幻/演唱会光感 |
| 暗角 | 强度 | 画面四角压暗，聚焦中心 |
| 锐化 | 强度 | 提升边缘清晰度 |
| 光学 | 抗锯齿 / 颗粒 / 色散 / 光晕 | 电影质感微调 |
| 环境（SSAO） | 开关 / 强度 / 半径 / 采样 | 接触阴影，增强立体感 |

## 常见问题

**Q：调了雾密度没反应？**
A：当前是 `linear` 线性模式——密度只在 `exp/exp2` 指数模式生效，改用「起止距离」。

**Q：开了 SSAO / Bloom 后变卡？**
A：这些是较重的后处理；在 [设置](./settings.md) → 画面降低画质档位，或关闭不需要的效果。
