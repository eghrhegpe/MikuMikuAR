# 雾设置

## 它能做什么

给场景添加**环境雾**：调整雾色、密度与起止范围，让远景自然隐入雾中，增强舞台纵深与氛围。

## 打开方式

1. 打开**场景**弹窗
2. 进入**环境 → 雾**（路由 `env:fog`）

## 操作步骤

### 1. 启用雾

- 打开「雾」开关，场景即开始应用雾效。

### 2. 调整外观

| 参数 | 作用 |
|------|------|
| 雾颜色 | 雾色（偏蓝冷峻、偏暖柔和） |
| 雾起 / 雾止 | 雾的起始与完全遮挡距离（`start` / `end`） |
| 密度 | 雾的浓淡（距离相同下更密更不透明） |

### 3. 与水面/水下联动

- 水面设置中也有「雾颜色 / 雾起止」——那是**水下/远景**专用雾，与此处环境雾独立，可分别调节。

## 常见问题

**Q：雾太浓看不清角色？**
A：把「雾止」距离调远，或降低密度——雾的完全遮挡点在雾止处。

**Q：环境雾与水面雾冲突？**
A：二者独立控制：环境雾在此处调，水面/水下雾在[水面设置](./env-water.md)里调。
