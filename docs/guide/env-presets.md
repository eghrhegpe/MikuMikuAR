# 环境预设

## 它能做什么

把当前环境参数（天空、水面、粒子、风、雾等）**保存为预设**，之后一键还原；内置「场景氛围」方案（舞台、户外晴天、演唱会、摄影棚、黄昏、雨天等）。

## 打开方式

1. 打开「**环境**」弹窗
2. 进入「预设」（路由 `env:presets`）

## 操作步骤

### 1. 应用内置氛围

- 预设分区 →「场景氛围」→ 选择方案（演唱会 / 户外晴天 / 黄昏 / 雨天…）
- 一键切换整套环境，快速进入演出状态

### 2. 保存当前环境为预设

- 调整好天空/水面/粒子后 →「＋ 保存当前为预设」→ 输入名称
- 之后在「我的预设」中一键复用

### 3. 管理预设

- 选中预设 →「删除」；预设以文件形式存于资源目录，可跨项目复用

![环境预设面板](img/env-presets-1.png)

## 常见问题

**Q：预设保存后找不到？**
A：确认保存在「我的预设」分组；预设文件按名称存放，重名会被覆盖（保存时会有提示）。

**Q：环境预设和场景预设什么区别？**
A：环境预设只管环境参数（天空/水面/粒子等）；场景预设还包含模型布局、灯光、相机等舞台整体状态（见「场景 → 预设场景」）。
