# 风力与粒子

## 它能做什么

给舞台加**风**和**天气粒子**：风向与风速让模型的裙摆、头发朝一个方向飘动；粒子系统叠加雨、雪等天气效果，营造场景氛围。

## 打开方式

1. 打开「**环境**」弹窗
2. 风：进入「风」分区（路由 `env:wind`）；粒子：进入「粒子」分区（路由 `env:particle`）

## 操作步骤

### 1. 调整风（配合布料物理）

| 参数 | 范围 | 作用 |
|------|------|------|
| 风向角度 | 0–360° | 风吹的水平方向（罗盘角度） |
| 风速 | 0–10 | 风力大小，越大布料飘动越明显 |

> 风只对**带物理骨骼的布料**生效，且需先在 [布料物理](./physics.md) 里有合适的重力。风速为 0 时布料只受重力自然下垂。

### 2. 天气粒子

| 参数 | 作用 |
|------|------|
| 粒子类型 | 选择雨 / 雪 / 无等类型 |
| 密度 | 粒子数量多少 |
| 大小 | 单颗粒子尺寸 |
| 速度 | 粒子下落/飘动速度 |
| 水花 | 开启后粒子落地泛起水花（雨天效果） |

## 常见问题

**Q：调了风速裙摆纹丝不动？**
A：确认模型带物理骨骼，且 [布料物理](./physics.md) 的重力不为 0；纯静态模型不受风影响。

**Q：粒子太多导致卡顿？**
A：调低「密度」，或在 [设置](./settings.md) → 画面降低画质档位。
