# 镜面反射

## 它能做什么

给舞台添加**反射效果**：地面像镜子一样映出模型与灯光。支持多种反射模式（无 / 平面反射 / SSR / 探针 / 混合），按画质与场景需求选择。

## 打开方式

1. 打开**场景**弹窗
2. 进入**镜面**（路由 `scene:mirror`）

## 操作步骤

### 1. 选择反射模式

| 模式 | 效果 | 适用 |
|------|------|------|
| 无 | 关闭反射 | 低配/不需要 |
| 平面反射（planar） | 地面镜面映照，效果最直观 | 舞台表演、对称构图 |
| SSR | 屏幕空间反射，实时感强 | 需要高质量反射时 |
| 探针（probe） | 环境探针采样，开销小 | 中低配的通用反射 |
| 混合（hybrid） | 平面 + SSR 组合 | 追求最佳画质 |

### 2. 调质量

- 质量档位影响反射分辨率与更新频率（高 / 中 / 低）；性能紧张时降低档位或切「探针」模式。

### 3. 与水面区分

- **镜面反射**作用于舞台地面；**水面反射**是水面自身的倒影——两者独立，见[水面设置](./env-water.md)。

## 常见问题

**Q：反射看不到模型？**
A：确认反射模式已开启（非「无」），且模型在反射平面之上；平面反射对地面高度敏感，可先调[地面设置](./ground.md)的「地面高度」。

**Q：性能明显下降？**
A：切「探针」模式或降低质量档位——平面/SSR 开销最大。
