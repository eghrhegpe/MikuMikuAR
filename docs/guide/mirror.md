# 镜面反射

## 它能做什么

给舞台添加**反射效果**：地面像镜子一样映出模型与灯光。支持多种反射模式（无 / 平面反射 / SSR / 探针 / 混合），按画质与场景需求选择。

## 打开方式

1. 打开**场景**弹窗
2. 进入**镜面**（路由 `scene:mirror`）

## 操作步骤

### 1. 开启镜面

- 场景弹窗 → **镜面**文件夹，头部开关即启用 / 关闭反射（同级的「反射质量」滑块可一并调）。

### 2. 选反射模式与质量

- **反射模式**（场景根菜单同级滑块）：无 / 平面（planar）/ SSR / 探针（probe）/ 混合（hybrid）。
- **反射质量**：关闭 / 低 / 中 / 高，影响反射分辨率与更新频率；性能紧张时降低档位或切「探针」模式。

### 3. 调镜面尺寸

- 进入**镜面**子层（路由 `scene:mirror`）：用「宽度（0–40）/ 高度（0–30）」两个滑块控制镜面平面大小。

### 4. 与水面区分

- **镜面反射**作用于舞台地面；**水面反射**是水面自身的倒影——两者独立，见[水面设置](./env-water.md)。

## 常见问题

**Q：反射看不到模型？**
A：确认反射模式已开启（非「无」），且模型在反射平面之上；平面反射对地面高度敏感，可先调[地面设置](./ground.md)的「地面高度」。

**Q：性能明显下降？**
A：切「探针」模式或降低质量档位——平面/SSR 开销最大。
