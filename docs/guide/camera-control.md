# 相机操作

## 它能做什么

控制 3D 舞台的**观察视角**：轨道相机环绕模型、自由飞行相机漫游场景，并可微调灵敏度、反转 Y 轴等参数。

## 打开方式

- 动作面板 →「相机」分区
- 或直接拖拽舞台（轨道模式默认）

## 操作步骤

### 1. 选择相机模式

| 模式 | 适合场景 | 操作 |
|------|---------|------|
| 轨道（ArcRotate） | 围绕模型旋转查看 | 左键拖拽旋转、滚轮缩放、右键平移 |
| 自由飞行（Freefly） | 舞台漫游、贴近观察 | WASD 移动 + 鼠标转向（快捷键见设置 → 快捷键） |

### 2. 调整手感

- **设置 → 操控**「相机灵敏度」滑块：控制旋转/缩放/平移速度
- **设置 → 操控**「反转 Y 轴」开关：垂直拖拽方向反转（轨道模式生效）
- 相机分区「移动速度」滑块：自由飞行模式下的移动快慢

### 3. 相机行为（自动运镜）

- 相机分区「行为」：静止（手动）/ 环绕（模型绕转）/ 演唱会 / 自动运镜 / VMD 相机
- 选「环绕」后模型会缓慢自转展示；「自动运镜」按节拍自动切机位

### 4. 镜头参数（景深等）

- 相机分区「镜头（景深）」：调整对焦距离、光圈与焦距，实现虚化效果（属于镜头参数，非后期滤镜）

## 常见问题

**Q：相机被模型挡住看不清？**
A：使用自由飞行模式靠近，或调小相机「近裁面」。

**Q：旋转方向和我习惯相反？**
A：开启「反转 Y 轴」，或在设置 → 快捷键中查看/修改相机键位。
