# 云层设置

## 它能做什么

在天空中生成**动态云层**：程序化噪声驱动云朵形状，支持密度、移动速度和透明度调节，让天空更有层次感。

## 打开方式

1. 打开**场景**弹窗（点击主界面「场景」按钮）
2. 进入**环境 → 云**（路由 `env:cloud`）

## 操作步骤

### 1. 启用水面云层

- 打开「云」开关，云层即出现在天空，默认缓慢飘动。

### 2. 调整外观

| 参数 | 作用 |
|------|------|
| 云层密度 | 云朵数量与覆盖率 |
| 移动速度 | 云层飘动快慢（可为 0 定格） |
| 透明度 | 云朵半透明程度 |

### 3. 与天空联动

- 云层叠加在天空之上，配合[天空设置](./sky.md)的模式（纯色/贴图/HDR）共同构成天空氛围。

## 常见问题

**Q：云层不明显或太淡？**
A：调高「云层密度」并降低「透明度」试试。

**Q：云层不动？**
A：检查「移动速度」是否为 0——设为 0 是刻意定格行为。
