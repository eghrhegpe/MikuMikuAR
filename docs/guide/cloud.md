# 云层设置

## 它能做什么

在天空中生成**动态云层**：程序化噪声驱动云朵形状，支持密度、移动速度和透明度调节，让天空更有层次感。

## 打开方式

1. 打开**场景**弹窗（点击主界面「场景」按钮）
2. 进入**环境 → 云**（路由 `env:cloud`）

## 操作步骤

### 1. 启用云层

- 打开「云」开关，云层即出现在天空，默认缓慢飘动。

### 2. 调整外观

| 参数 | 作用 |
|------|------|
| 云覆盖 | 云朵覆盖率（cloudCover） |
| 云间隙 | 云块间空隙（cloudGap） |
| 侵蚀 | 云朵边缘侵蚀程度（cloudErosion） |
| 天气强度 | 风/天气扰动强度（cloudWeatherStrength） |
| 高度 / 缩放 / 厚度 | 云层所在高度、整体缩放、体积厚度 |
| 可见度 | 云层出现的距离（cloudVisibility） |
| 背光 / 粉度 | 背光强度与粉末感（cloudBacklight / cloudPowder） |

### 3. 与天空联动

- 云层叠加在天空之上，配合[天空设置](./sky.md)的模式（纯色/贴图/HDR）共同构成天空氛围。

## 常见问题

**Q：云层不明显或太淡？**
A：调高「云层密度」并降低「透明度」试试。

**Q：云层看不出变化？**
A：调高「云覆盖」与「天气强度」可看到更明显的云形与扰动；「可见度」控制云层开始出现的距离。
