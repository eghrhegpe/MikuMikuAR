# 拖拽模式

## 它能做什么

不用滑块、直接**在 3D 画面上拖拽**模型 / 道具 / 舞台：选中后拖动即可改变位置，配合「吸附设置」让物体对齐到网格或按步长移动，摆场景更快更直观。

## 打开方式

1. 打开**场景**弹窗
2. 进入**拖拽模式**（路由 `scene:dragMode`）
3. 场景弹窗根级「拖拽模式」**头部开关**即总闸：开 → 挂载拖拽并自动选中当前模型；关 → 卸载拖拽

## 操作步骤

### 1. 开启拖拽

- 打开头部开关（或直接进「拖拽模式」文件夹）。开启后画布上点选模型即可拖动。

### 2. 吸附设置

- 进入「拖拽模式」子面板（路由 `scene:dragMode`）：
  - **吸附开关**：开启后拖拽按步长吸附，摆位更规整
  - **位置 / 旋转 / 缩放步长**：各自独立的吸附间隔（如位置按 0.1 单位、旋转按 15°）
- 关闭吸附 = 自由连续移动，适合微调。

### 3. 与变换滑块配合

- 拖拽适合大范围摆放；要精确到小数位仍可用模型详情里的「变换滑块」（位置 / 旋转 / 缩放）。

## 常见问题

**Q：开了拖拽但点模型没反应？**
A：确认头部开关是「开」状态；再确认点选的是可拖拽的模型/道具，舞台背景（天空/地面）不支持拖拽。

**Q：拖歪了想精确归位？**
A：打开「吸附」并按步长拖动，或改用模型详情的变换滑块输入精确值。
