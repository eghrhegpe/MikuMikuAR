# AI 助手

## 它能做什么

内置的 **AI 诊断助手**：用自然语言提问排查问题，或直接下指令**控制场景**（如「把重力调小」「切换到夜晚」）。对话历史自动保存，可随时切换/新建会话。

## 打开方式

- 主界面底部「**AI 助手**」按钮（快捷键 Ctrl+8），或 主界面 → **设置** → 「AI 助手 / 诊断」页
- 面板分**对话**与**配置**两个标签页

## 操作步骤

### 1. 首次配置（对话前必做）

- 切到「**配置**」标签 → 填写 **API 端点** 与 **模型名称** → 选择 AI 服务商 → 点「连接测试」。
- 配置正确后回到「对话」标签即可开始。

> 未配置端点/模型时对话无法发送——这是最常见的「AI 不回复」原因。

### 2. 对话答疑

- 在「对话」标签输入问题，回复**流式逐字**显示。
- 发送后可**中断**正在生成的回复（再点发送键/停止）。

### 3. 自然语言控场

- 直接下达指令（如「让角色开始跳舞」「把水面打开」），助手会解析成动作并执行。
- 涉及**破坏性操作**（删除、重置）时会弹出**待确认队列**，需你确认后才执行。

### 4. 会话管理

- 会话自动存本地（IndexedDB），可在会话列表**切换 / 新建 / 删除**。

## 常见问题

**Q：AI 一直不回复？**
A：99% 是「配置」标签的端点或模型名没填对——先点「连接测试」验证。

**Q：说了指令但场景没变化？**
A：并非所有表述都能解析成动作；换更明确的说法（对应菜单里的功能名），或手动操作对应面板。
