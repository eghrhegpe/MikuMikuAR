# 设置

## 它能做什么

集中管理应用级配置：**性能模式、外观主题、资源路径、快捷键、语言、截图与音频默认值**——不针对某个舞台，而是全局生效。

## 打开方式

- 点击主界面「**设置**」按钮（或按快捷键，见设置 → 快捷键）

## 操作步骤

### 1. 性能（低配设备优先看这里）

| 选项 | 作用 |
|------|------|
| 性能模式 | 自动 / 质量优先 / 平衡 / 性能优先 / 自定义 |
| 帧率上限 | 限制帧率省电（移动端建议 30） |
| 渲染分辨率缩放 | 低于 100% 提升帧率，高于 100% 超采样更清晰 |
| 默认物理开关 | 关闭可显著提升低配帧率 |

### 2. 外观

- 主题色（经典蓝 / 樱花粉 / 薄荷绿 / 日落橙 / 暗夜紫 / 极简灰）
- UI 缩放 / UI 尺寸 / 字体（系统默认 / 思源黑体 / 微软雅黑）
- 背景模糊、滑动动画开关

### 3. 路径（首次使用必配）

- 资源根目录：模型/动作/音乐的存放根目录
- 下载文件夹：扫描导入新文件的目录（可开启自动导入）
- 截图保存目录、音频默认音量等

### 4. 快捷键

- 查看/修改全部快捷键（模型库、动作面板、播放控制、截图等）
- 点击条目 → 按下新组合键即可改绑；「恢复默认快捷键」一键还原

### 5. 语言与关于

- 语言：简体中文 / English / 日本語 / 한국어 / 繁體中文
- 关于：版本信息、缓存占用清理、设置导入导出

## 常见问题

**Q：改了设置不生效？**
A：多数设置即时生效；性能模式中「自定义」需逐项勾选渲染项（阴影/泛光/FXAA 等）。

**Q：资源根目录怎么选？**
A：选择包含模型文件夹的父目录即可；模型库会递归扫描子目录（PMX/VMD/音频/ZIP）。
