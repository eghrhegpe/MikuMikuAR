# 视线追踪

## 它能做什么

给角色注入「**活人感**」：头部与眼球随相机移动而转动（视线追踪）、自然呼吸、随机眨眼——统称**感知层**微动。无需 VMD 也能让模型看起来在「看着你」，AR / 待机场景尤其好用。

## 打开方式

1. 打开**动作**弹窗
2. 进入**更多 → 视线追踪**（路由 `motion:gaze`）

## 操作步骤

### 1. 开启视线追踪

- 面板顶部**总开关**启用头部/眼球追踪；也可逐项勾选「头部追踪」「眼球追踪」等模块（模块列表见面板内勾选组）。

### 2. 调追踪范围与平滑

| 参数 | 作用 | 参考范围 |
|------|------|---------|
| 头部偏航范围 | 头部左右转动的最大角度 | 0–90° |
| 头部俯仰范围 | 头部上下转动的最大角度 | 0–90° |
| 眼球偏航范围 | 眼球左右转的最大角度 | 0–15° |
| 眼球俯仰范围 | 眼球上下转的最大角度 | 0–15° |
| 眼球平滑 | 跟随的平滑/响应速度 | 0–1 |

> 范围越小越「克制自然」，太大像「脖子扭到」。

### 3. 呼吸与眨眼

- **呼吸频率/幅度**：胸廓与肩部的起伏周期与大小
- **眨眼频率/幅度**：眨眼间隔与闭合程度
- 均可独立开关，配合视线追踪让角色「活」起来。

### 4. 全员感知（多模型）

- 多模型同场时可开启「全员感知」并选档位（高/中/低），性能紧张时降档。

## 常见问题

**Q：开了追踪但角色不动？**
A：确认对应模块（头部/眼球）已勾选，且未与动作覆盖冲突（面板顶部有冲突提示横幅）；VMD 播放中骨骼可能被动作占据。

**Q：转动太夸张不自然？**
A：调小「头部偏航/俯仰范围」，眼球保持小范围（<10°）更真实。
