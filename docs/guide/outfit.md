# 换装

## 它能做什么

给舞台上的模型**切换服装变体**：在模型自带的换装配置里挑选不同套装，部分变体还会叠加 FBX 网格服饰（如外套、配饰）。随时可一键**重置回默认外观**。

## 打开方式

1. 选中舞台上的模型 → 打开**模型详情**
2. 进入「**换装**」子菜单

> 换装列表来自模型自带的换装配置；没有配置的模型会提示「暂无换装配置」。

## 操作步骤

### 1. 切换服装变体

- 换装面板会列出「默认」+ 该模型的所有变体，当前生效项左侧显示 ✓ 勾选图标。
- 点击任一条目即可切换；切换时顶部状态栏提示「切换中…」，完成后提示「已切换」。

### 2. 认识 FBX 变体

- 名称右侧带 **FBX** 标记的变体，会在原模型上**叠加一层 FBX 网格服饰**（而非仅替换贴图）。
- 无标记的变体是**纹理替换**（换贴图，不加网格），切换更快。

### 3. 重置外观

- 面板底部「**重置所有**」按钮：一键移除所有换装叠加，模型回到最初加载时的外观。

## 常见问题

**Q：换装面板是空的 / 提示「暂无换装配置」？**
A：该模型没有随附换装配置文件——换装变体由模型作者预先定义，不是所有模型都有。

**Q：连续快速点击多个变体会不会出错？**
A：不会。换装有加载守护，切换未完成时的重复点击会被忽略，等当前切换结束再操作即可。

**Q：切换 FBX 变体后想干净地换回来？**
A：用底部「重置所有」，比逐个切回「默认」更彻底（会清掉叠加的 FBX 网格）。
