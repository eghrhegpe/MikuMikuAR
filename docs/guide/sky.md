# 天空设置

## 它能做什么

控制舞台**背景天空**：渐变天空、立方图/HDRI 天空盒、太阳高度与颜色，营造从晴天到黄昏的氛围。

## 打开方式

1. 打开「**环境**」弹窗（点击主界面「环境」按钮）
2. 进入「天空」分区（路由 `env:sky`）

> 注：天空挂环境菜单；而水面/地面因历史原因挂场景菜单（路由 `scene:water` / `scene:ground`），前缀不同属正常。

## 操作步骤

### 1. 选择天空模式

| 模式 | 效果 |
|------|------|
| 渐变 | 程序化天空（顶色/地平线色），性能最好 |
| 立方图 | 加载天空盒贴图（.hdr / .dds / .exr），真实感最强 |
| 星空 | 夜晚星空背景 |

### 2. 调整氛围

- 「天空颜色顶部 / 地平线」：渐变天空的两个关键色
- 「太阳位置」：控制光照方向与明暗
- 「环境反射强度」：天空作为场景反射光源的强度

![天空设置](img/sky-1.png)

### 3. 加载自定义天空盒

- 立方图模式 →「选择天空纹理」→ 选择 HDR/DDS 文件（也可从 [模型导入](./import-model.md) 拖拽）

## 常见问题

**Q：天空盒加载后是黑的？**
A：确认文件为 .hdr / .dds / .exr 格式，且已开启「环境反射强度」——天空同时是反射光源，强度为 0 时看起来会发暗。
