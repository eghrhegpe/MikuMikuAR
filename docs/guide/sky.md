# 天空设置

## 它能做什么

控制舞台**背景天空**：纯色天空、立方图/HDRI 天空盒、程序化天空与星星，以及太阳、全局亮度等光照氛围，营造从晴天到黄昏的效果。

## 打开方式

1. 打开「**环境**」弹窗（点击主界面「环境」按钮）
2. 进入「天空」分区（路由 `env:sky`）

> 注：天空挂环境菜单；而水面/地面因历史原因挂场景菜单（路由 `scene:water` / `scene:ground`），前缀不同属正常。

## 操作步骤

### 1. 选择天空模式

| 模式 | 效果 |
|------|------|
| 纯色 | 单一颜色天空（天空颜色顶部），性能最好 |
| 贴图 | 加载天空盒贴图（.hdr / .dds / .exr），真实感最强 |
| 程序化 | 程序化天空（天顶色 / 地平线色），可叠加星星 |

> 顶部还有「时光预设」芯片（黎明 / 正午 / 夕阳 / 夜景 / 阴天 / 霓虹），一键切换不同时段氛围。

### 2. 调整氛围

- 「天空颜色顶部」（纯色模式）/「天顶颜色 / 地平线颜色」（程序化模式）：天空两个关键色
- 「旋转速度」：天空缓慢旋转营造动态感
- 「光照控制」折叠组：
  - 「太阳强度」：主光源明暗
  - 「天空照明」：天空作为场景反射光源的强度（0 时天空看起来会发暗）
  - 「全局亮度」：整体环境亮度
  - 「星星」（程序化模式）：夜晚星空开关，可换星星贴图

![天空设置](img/sky-1.png)

### 3. 加载自定义天空盒

- 贴图模式 →「选择天空纹理」→ 选择 HDR/DDS 文件（也可从 [模型导入](./import-model.md) 拖拽）

## 常见问题

**Q：天空盒加载后是黑的？**
A：确认文件为 .hdr / .dds / .exr 格式，且「光照控制 → 天空照明」不为 0——天空同时是反射光源，强度为 0 时看起来会发暗。
