# 阴影设置

## 它能做什么

控制场景**阴影**：环境主光（方向光）的级联阴影与舞台灯阴影。可调阴影类型（硬/软/PCF）、分辨率、级联数与偏移，让模型与地面更"落地"。

## 打开方式

1. 打开**场景**弹窗
2. 进入**环境 → 阴影**（路由 `env:shadow`），或 **舞台灯光 → 阴影**（路由 `scene:stageLight`）

## 操作步骤

### 1. 启用阴影

- 打开「阴影」开关，模型/道具即向地面投射阴影。

### 2. 调整参数

| 参数 | 作用 |
|------|------|
| 阴影类型 | hard（硬边）/ soft（软边）/ pcf（柔和滤波） |
| 分辨率 | 阴影贴图分辨率（越高越清晰、越吃性能） |
| 级联数 | CSM 级联数量（大场景防近处糊） |
| 偏移（bias） | 阴影深度偏移（调大防"阴影条纹/抖动"） |

### 3. 舞台灯阴影

- 每盏舞台灯可单独开阴影：舞台灯光 → 选中灯 → 阴影开关/强度。

## 常见问题

**Q：阴影有条纹/抖动（shadow acne）？**
A：调大「偏移（bias）」——这是已知的深度精度问题，微调即可消除。

**Q：阴影模糊或缺失？**
A：先确认环境主光存在且「阴影」开关开启；再调高「分辨率」/「级联数」。
