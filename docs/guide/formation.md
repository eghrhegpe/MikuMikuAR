# 队形编排

## 它能做什么

给舞台上**多个模型**批量排**队形**：按网格、圆形等预设排列，快速完成演唱会/合唱等群体站位，省去逐个拖拽调整。

## 打开方式

1. 加载多个模型到舞台（见[模型导入](./import-model.md)）
2. 打开**模型库**弹窗
3. 进入**队形**（路由 `models:formation`）

## 操作步骤

### 1. 选择队形

- 选择预设队形（网格 / 圆形等），已加载模型自动按该队形重新站位。

### 2. 调整参数

- 队形类型参数（如网格的行列数 / 圆形的半径）与模型间距，按需微调。

### 3. 单独微调

- 队形是批量站位；个别模型想再微调，用模型详情 →「变换」拖动即可（队形后手动调整）。

## 常见问题

**Q：队形只对部分模型生效？**
A：确认模型已全部加载到舞台（队形作用于已加载模型集合）；未加载模型不会参与排列。

**Q：想恢复自由站位？**
A：重新选择队形或逐模型用「变换」调整即可（队形不锁定位置）。
