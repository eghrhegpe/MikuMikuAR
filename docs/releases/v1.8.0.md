# v1.8.0

## 新功能

### 纹理系统 (ADR-189 延伸)
- 多候选路径 fallback：深子目录贴图可被带目录前缀的 PMX 声明命中
- 声明路径别名注册：目录名异写兜底（`tex\` vs `Texture\`）
- 检测 PMX 声明但缺失的纹理并提示用户
- 统一资源加载失败汇总提示（模型纹理 / 换装 / 音频缺失）

### 声明式菜单与交互自动化 (ADR-229)
- schema-driven 交互行为自动化（`action` 字段），导航元数据上移注册器
- DOM 契约统一：dom-contract 单源 + 快照携带选择器 (§9)
- 菜单 schema 快照泛型化

### 地面视觉 (ADR-231)
- 地面自发光地屏 + scan / glowEdge 叠加落地
- 镜面几何参数迁入 `envState`，修复持久化缺失
- 地面 scan 环动画覆盖贴图地面，相位连续不跳变

### 材质与渲染
- KTX2 转码挂到设置开关（修复 toktx v4.4.2 语法）
- SSS 材质类型收窄与鸭子类型标记移除
- 抗锯齿唯一入口移至设置页，后处理面板增加还原默认
- AI 灯光守卫用户反馈

### 程序化动作与运动
- `proc-motion` 深拷贝与 per-mode 兜底参数修复
- 程序化动作统一进动作详情页 (ADR-207)
- 程序化动作覆盖审计收尾 (P3/P4)

### 工程治理
- ADR 取代关系扫描脚本 `gen-adr-supersede` + 文档守护链补全（funcmap / menumap / 路由冲突检测）
- 用户指南自动生成文档索引 + 指南覆盖缺口扫描 `gen-guide-gap`
