# v1.10.0

> **里程碑版**：自 v1.9.1 以来 543 个 commit —— 15 项新功能 + 232 项修复（含 16~73 轮子代理审计闭环）+ 8 项性能优化。重点：程序化动作工具栏、WASM IK 骨骼修复、系统代理出站支持、模型广场地址栏，以及贯穿全项目的 NaN 防护与 `guardNum` 治理。

## 新功能

- **程序化动作工具栏**：模型详情页行尾新增 `settings-2` 入口，程序化动作一键配置
- **WASM IK 骨骼写入修复**：babylon-mmd fork 的 WASM 运行时骨骼写入正确性修复
- **ADR-248 调试日志面板**：环形日志面板（设置 → 系统 → 缓存占用 → 打开日志面板），不再死盯 console
- **反向代理出站支持系统代理**：`HTTPS_PROXY` / `HTTP_PROXY` 环境变量生效
- **模型广场增强**：
  - 内置站点列表新增 GitHub，`directNavigate=false` 走代理剥离 `frame-ancestors` CSP
  - 内嵌模式新增地址栏：URL 显示 + 手动输入导航
- **下载进度显示更新**：进度反馈更实时、更准确
- **i18n 补齐**：`settings.resetAppearanceConfirm` 确认文案 5 语言包

## 修复

### 数值健壮性（P0 专项）
- **NaN 传播防护体系**：`guardNum` 全局化，堵住 5 处源码 NaN 漏洞：
  - `Matrix.Compose` 前 Vector3 分量守卫（gaze WASM + layers blender）
  - lighting-tween `Color3` 构造 + motion-intent ratio `Infinity` 兜底
  - vmd-writer clamp 守卫 + feet-adjustment NaN 保护
  - motion-modules params 读取统一走 `guardNum`（`?? 0` 不挡 NaN 的缺口）
- **ui-state**：`mergeUIState` 改用 presence mask——合法零值与 partial bool 不再丢失
- **fullscreen-overlay**：真实 `.slide-menu` 选择器 + 多实例冻结恢复
- **`getPersonalLightState`**：color 数组深拷贝，彻底隔离外部原地误改
- **场景切换**：`onBack` 单次触发 / `patchPanel` 空态回退 / `disposeLighting` / `dispose` 复位矩阵（幽灵状态残留根治）
- **语言切换**：scene-menu 根 items 缓存 key 纳入 `getLang()`，修复根级标签停留旧语言（ADR-065）

### 大规模审计闭环（round 16~73）
