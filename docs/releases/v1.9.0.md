# v1.9.0

> 自 v1.8.0 起累计 110 次提交。本轮以**动作系统架构解耦（ADR-238）**与**感知状态场景级化（ADR-188/933fa46d）**为主线，叠加程序化动作预设、环境水体拆分、工程治理工具链升级，并修复一处口型逐帧抖动回归。

## 新功能

### 程序化动作预设（ADR-188 延伸）
- 程序化动作自定义预设：保存 / 应用 / 删除 + 持久化
- 程序化动作参数预设集：idle / autodance 一键应用
- ADR-188 model-preset SSS 序列化 / 恢复

### 动作系统架构解耦（ADR-238）
- `core → scene` 依赖边从 21 条收敛至 10 条，新增 `scene-action-bridge` / `ui-action-bridge` / `e2e-state-bridge` 注入桥
- init 启动编排、events / shortcut、motion / library、settings / scene、control 等动作实现下沉注册，定义留 core
- AR 双向依赖解耦、outfit 域资源释放桥接、model-loader / model-manager 骨骼覆写读取桥接

### 环境水体与感知
- ADR-239 env-water 拆模块：材质 / 着色器 / 平面反射 / FX 子系统拆分至独立文件
- 感知状态改场景级单例存储，消除 per-model 参数与编辑入口错配（933fa46d）

### 工程治理工具链
- `check-circular` 升级：`--edges` 边级归因、`--snapshot` / `--diff` 基线对比
- `check-consumers` 新增符号反向查询，重构前影响面预判
- `check` 顶层脚本冒烟测试 + funcmap 行号列
- env-state ↔ Go bindings 字段 parity 检查

## 修复

- **口型逐帧抖动回归**：`perception-lipsync.ts` 音源切换判定存在 `??` 优先级 bug（低于 `!==`），有音频时每帧恒真、平滑缓存逐帧清空；已修复为显式取 `audioPath` 后比较
- 感知状态 per-model 全量持久化，切换模型不丢参数（ab4ac72f）
- 感知状态改场景级存储后的 menu-schema modelId 分流、removeModel disposeAudio、playback tick / seek 桥接 7 处测试漂移修正
- 多类 fix 累计 17 处（含 menu-schema motionModule bind 单源、deadcode 基线、i18n 缺译）
