# v1.6.7

## 修复

### Android 私有目录存储切换 UI 缺失（关键）
- 根因：`capabilities` 异步预热缺失，`buildStorageSchema` 时拿到 `ALL_TRUE_CAPS` 的 `fsSelectDir=true`，走桌面路径隐藏了私有/共享存储切换 UI
- 修复：`init.ts` 增加 Android 端 `fireAndForget` 异步预热 capabilities；`settings-resources.ts` 将 `fsSelectDir` 从 build-time 捕获改为 render-time 延迟求值

## 测试

- 新增风力物理状态机单测（`wind-physics-state.test.ts`）：订阅/重试/销毁/幂等 14 个用例
- `isWindPhysicsActive` 导出供 E2E 钩子使用
