# v1.10.1

> **跟进版**：v1.10.0 发布后 26 commit —— 2 项 3D 渲染新功能（水面深度差雾、法线乘法混合）+ 12 项修复（重点在菜单层级动画竞态与时序）。用户定档为 patch 版本，内容包含功能增强如实记录。

## 新功能

- **ADR-222 水面深度差雾（Depth-Difference Fog）**：水面材质深度差雾效果，提升水体真实感
- **ADR-223 P0 法线乘法混合 + ADR-215 附属关系**：法线贴图乘法混合模式 + 附属骨骼关系支持，修复 P0 渲染一致性问题

## 修复

### 菜单层级动画（P0/P2 专项）
- 层级动画机制竞态 + 时序 + 语义统一修复（`_pendingReRender` 延迟到 transition 结束 flush）
- `autoExpand` 竞态治理：150ms 延迟 + 原子消费、push 推迟一帧、polling 期间跳过 `onLevelEnter` 自动展开
- 残留 timer/flag 清理：菜单 reset 与 dispose 时兜底清理（`guard fallback timers against level mismatch`）
- **lcard toolbar 滚动粘性**：滚动时工具栏保持可见

### 生命周期与死代码
- mesh 双重释放守卫 + 日志标签统一（P3/P4）
- `disposeMenuWrapper` / `clearAllMenuWrappers` 接线，消除零调用死代码（ADR-252）
- 注释与实现漂移修正（P1 审核发现）5 处

## 重构 / 工程

- **日志门控统一**：`logDebug` / `__debugLog` 门控单测补齐（4 用例），热路径日志纪律落地（ADR-248）
- `_cancelLightingTransition` 提取公共函数 + `onComplete` 异常隔离测试
- **vitest 并发 8→4 workers**：防 agent 对话中全量测试拖死对话节奏
