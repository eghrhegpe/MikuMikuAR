# v1.6.6

## 新功能

### 端能力声明式收口 (ADR-190)
- 淘汰散落各处的 `isAndroidPlatform` 分支，统一为 `capabilities` 声明式查询
- 能力矩阵补全宿主级键，四端统一收口

### 风物理系统修复 (ADR-194)
- 从「假风」到真实风场：粒子、水面、Bullet 物理三系统联动
- 水面 `uWindSpeed` 接入 `windEnabled` 守卫，关风时水面静止
- 风向量计算统一为 `wind-utils.ts`，四系统一致性运行时校验

### 模型稳定身份 (ADR-193)
- `inst.id` 改为持久化 uuid，替换模型继承身份，场景序列化稳定

### 上游适配层重构 (ADR-192)
- Phase 1：BoneFrameClock 时序契约 + PlaybackContract 切换契约
- Phase 2：条目 3 使用公开 API 内化 rigidBodyBundleReferenceCountMap，条目 9 改为守卫式反射

### 神桶去桶化 (ADR-191)
- `@/core/utils` 零依赖叶下沉为 `@/core/clamp`、`@/core/path`、`@/core/async`
- 消除神桶 import 导致的 vitest fork worker 挂死

### 下载文件夹统一 (ADR-195)
- 三平台系统下载目录统一 + 消除「二扫」
